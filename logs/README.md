# Raw Experiment Logs

このディレクトリには，データセット選定およびmutation testingで生成された
詳細な標準出力，標準エラー，コマンド実行記録をローカルに保存する。

大量かつ重複の多い生ログであるため，通常のGitリポジトリでは管理しない。

GitHubで管理する再現用データは次の場所に保存する。

- `metadata/`：対象ごとの集計結果および最終レポート
- `manifests/`：リポジトリ，対象，実験実行の一覧
- `experiments/`：LLM実験の入力，出力，評価結果
- `scripts/`：再実行に必要なスクリプト

生ログを外部へ保管する場合は，アーカイブのSHA-256と保存場所を
別途manifestへ記録する。
