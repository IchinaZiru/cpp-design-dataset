# デザイン文書: IPアドレスインターフェースと実装

## 概要
この設計文書は、IPアドレスを扱うための抽象クラス`IPAddr`とその派生クラス`IPv4Addr`、`IPv6Addr`について記述します。これらのクラスはネットワークプログラミングにおいてIPアドレスの操作を行うために使用されます。

## 責務
- IPアドレスのバージョンを取得する。
- ソケットアドレス構造体へのポインタを取得する。
- IPアドレスとポート番号を文字列として取得する。
- ネットワークバイトオーダーとホストバイトオーダー間での変換を行う。

## 公開インターフェース
### クラス: `IPAddr`
| 関数名 | 戻り値 | 説明 |
|--------|--------|------|
| `Version()` | int | IPアドレスのバージョンを返す。 |
| `Size()` | std::size_t | ソケットアドレス構造体のサイズを返す。 |
| `Raw()` | const sockaddr* | ソケットアドレスへのポインタを返す。 |
| `Port()` | std::uint16_t | ポート番号をホストバイトオーダーで返す。 |
| `IPAddress()` | std::string | IPアドレスを文字列として返す。 |

### クラス: `IPv4Addr`
| 関数名 | 戻り値 | 説明 |
|--------|--------|------|
| コンストラクタ(sockaddr_in) | - | sockaddr_in構造体からIPv4アドレスを初期化する。 |
| コンストラクタ(std::string, std::uint16_t) | - | IPアドレスとポート番号の文字列からIPv4アドレスを初期化する。 |

### クラス: `IPv6Addr`
| 関数名 | 戻り値 | 説明 |
|--------|--------|------|
| コンストラクタ(sockaddr_in6) | - | sockaddr_in6構造体からIPv6アドレスを初期化する。 |
| コンストラクタ(std::string, std::uint16_t) | - | IPアドレスとポート番号の文字列からIPv6アドレスを初期化する。 |

## 入力
- `IPv4Addr`および`IPv6Addr`のコンストラクタは、IPアドレスとポート番号を受け取る。

## 出力
- 各関数は指定された情報を返す。

## 状態
- IPアドレスとポート番号を保持するプライベートメンバ変数を持つ。
- IPv4Addr: `ip_`, `raw_`
- IPv6Addr: `ip_`, `raw_`

## 処理手順
1. コンストラクタが呼び出される。
2. IPアドレスとポート番号を初期化する。
3. 必要に応じてネットワークバイトオーダーへの変換を行う。

## 例外・失敗条件
- `inet_pton`または`inet_ntop`の呼び出しでエラーが発生した場合、システムエラーコードをスローする。

## 依存関係
- `<concepts>`
- `<cstdint>`
- `<string>`
- `<string_view>`
- `<netinet/in.h>`
- `<arpa/inet.h>`

## 重要な不変条件
- `IPv4Addr`と`IPv6Addr`のインスタンスは、それぞれ正しい形式のIPアドレスとポート番号を持つこと。
- `Raw()`が返すポインタは有効なソケットアドレス構造体を指していること。
