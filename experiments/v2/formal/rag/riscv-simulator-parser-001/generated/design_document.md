# デザイン文書: Parser クラス

## 1. 概要と責務
`Parser`クラスは、入力ストリームからデータを読み取り、それをメモリに書き込む役割を持っています。主な機能として、16進数形式の文字列を解析し、その値を指定されたメモリアドレスに格納します。

## 2. 構造図

```mermaid
        +static void parse(std::istream &in, Memory &mem)
        +static void parse_hex(std::istream &in, Memory &mem)
    }
    
    class Memory {
        +void write_word(unsigned addr, char data)
        +char& operator[](unsigned addr)
    }

    Parser --> Memory
```

## 3. インターフェースと依存関係

- **完全な名前**: `Parser::parse_hex`
- **引数**:

- **戻り値**: `unsigned` - 16進数文字列を解析した結果の整数値。
- **修飾**: `static`

- **修飾**: `static`
- **使用するメンバ・型**: `std::string`, `std::getline`, `std::stringstream`, `strtol`

- **依存**: `<iostream>`, `<sstream>`, `<string>`
