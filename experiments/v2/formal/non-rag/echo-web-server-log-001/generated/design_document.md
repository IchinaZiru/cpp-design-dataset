# デザイン文書

## 概要
この設計文書は、与えられたソースファイル群を基にしたログシステムの再実装に必要な情報を提供します。各ファイルの責務、公開インターフェース、入力、出力、状態、処理手順、例外・失敗条件、依存関係、重要な不変条件について詳細に記載しています。

## モジュール構造

### include/log.h
- **責務**: ログシステムの主要なクラスと列挙型を定義する。
- **公開インターフェース**:
  - `Level`: ログレベルを表す列挙型。
  - `AppenderType`: アペンダーの種類を表す列挙型。
  - `Event`: ログイベントを表現するクラス。
  - `Formatter`: イベントフォーマッタを表現するクラス。
  - `Appender`: イベントを特定の場所に書き出す抽象基底クラス。
  - `StdOutAppender`: 標準出力にイベントを書き出すクラス。
  - `FileAppender`: ファイルにイベントを書き出すクラス。
  - `Logger`: アペンダーのリストを持つロガークラス。同期的または非同期的に動作する。
  - `Manager`: ロガーマネージャークラスで、ロガーのコレクションを維持する。

### src/log/log.cpp
- **責務**: `include/log.h`で定義されたクラスの実装を行う。
- **公開インターフェース**:
  - 各クラスのコンストラクタとデストラクタ。
  - メンバ関数: イベント作成、ロギング、フォーマット、アペンダー操作など。

### src/log/appender.cpp
- **責務**: アペンダークラスの実装を行う。
- **公開インターフェース**:
  - 各クラスのコンストラクタとデストラクタ。
  - メンバ関数: ログ出力、フォーマッタ操作など。

### src/log/field.h
- **責務**: イベントフィールド用のサブフォーマッタを定義する。
- **公開インターフェース**:
  - 各フィールドクラス: メッセージ、レベル、スレッドID、日時など。

### src/log/field.cpp
- **責務**: `src/log/field.h`で定義されたサブフォーマッタの実装を行う。
- **公開インターフェース**:
  - 各クラスのコンストラクタとデストラクタ。
  - メンバ関数: フォーマット処理など。

### src/log/config_init.h
- **責務**: ロガー設定初期化用の構造体とユーティリティを定義する。
- **公開インターフェース**:
  - `AppenderConfig`: アペンダーコンフィグレーションを表現する構造体。
  - `LoggerConfig`: ロガーコンフィグレーションを表現する構造体。

### src/log/config_init.cpp
- **責務**: `src/log/config_init.h`で定義された構造体の実装を行う。
- **公開インターフェース**:
  - 各構造体の比較演算子。
  - `SetListener`: ロガー設定変更時のリスナーを設定する関数。

## 詳細設計

### include/log.h

#### Event
- **入力**: ログレベル、ソースロケーション、スレッドID、イベント時間。
- **出力**: イベントの詳細情報（メッセージ、ファイル名、行番号など）。
- **状態**: メッセージストリーム、ログレベル、ソースロケーション、スレッドID、イベント時間。
- **処理手順**:
  - コンストラクタで初期化。
  - `MessageStream()`でメッセージを追加。
- **例外・失敗条件**: 無し。

#### Formatter
- **入力**: フォーマットパターン。
- **出力**: フォーマットされたイベント文字列。
- **状態**: パターン、フィールドリスト。
- **処理手順**:
  - コンストラクタで初期化。
  - `Format()`でイベントをフォーマットする。
- **例外・失敗条件**: 無効なパターンの場合`std::invalid_argument`。

#### Appender
- **入力**: フォーマットパターンまたはフォーマッタ。
- **出力**: イベントの書き込み先（標準出力、ファイルなど）。
- **状態**: ミューテックス、フォーマッタ。
- **処理手順**:
  - コンストラクタで初期化。
  - `Log()`でイベントを書き込む。
  - `SetFormatter()`でフォーマッタを設定する。
- **例外・失敗条件**: 無効なパターンの場合`std::invalid_argument`。

#### Logger
- **入力**: ロガー名、ログレベル、キュー容量。
- **出力**: イベントの処理（同期的または非同期的）。
- **状態**: 名前、レベル、キャパシティ、アペンダーリスト、イベントキュー、フォーマッタ。
- **処理手順**:
  - コンストラクタで初期化。
  - `Log()`でイベントを処理する。
  - `AddAppender()`, `RemoveAppender()`, `ClearAppenders()`でアペンダーを操作する。
  - `SetDefaultFormatter()`でデフォルトフォーマッタを設定する。
- **例外・失敗条件**: 無効なパターンの場合`std::invalid_argument`。

#### Manager
- **入力**: マネージャー名。
- **出力**: ロガーの管理（追加、削除）。
- **状態**: 名前、ロガーマップ。
- **処理手順**:
  - コンストラクタで初期化。
  - `FindLogger()`, `RemoveLogger()`でロガーを操作する。
- **例外・失敗条件**: 無し。
