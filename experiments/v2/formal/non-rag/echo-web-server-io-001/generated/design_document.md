# デザイン文書: I/Oモジュール

## 概要
この設計文書は、`include/io.h`と`src/io/io.cpp`に含まれるI/O操作に関するクラスの設計を詳細に記述します。各ファイルの責務、公開インターフェース、入力・出力、状態、処理手順、例外・失敗条件、依存関係、重要な不変条件について説明します。

## ファイル構造と責務

### include/io.h
- **ファイルの役割**: I/O操作に関連するクラスの定義を提供します。
- **公開インターフェース**:
  - `IReader`: バッファからの読み込みを行うためのインターフェース。
    - `ReadFrom(Buffer& buf)`: バッファからデータを読み込む。
  - `IWriter`: バッファへの書き込みを行うためのインターフェース。
    - `WriteTo(Buffer& buf)`: バッファにデータを書き込む。
  - `IReadWriter`: 読み込みと書き込みの両方を行えるインターフェース。
  - `Null`: データの読み書きを行わず、バッファの可読または可書込領域を消費するクラス。
    - `WriteTo(Buffer& buf)`: バッファの可書込領域を全て消費する。
    - `ReadFrom(Buffer& buf)`: バッファから全てのデータを削除する。
  - `StringStream`: 文字列ストリームとの読み書きを行うクラス。
    - コンストラクタ: 読み込み用と書き込み用の文字列ストリームを受け取る。
    - `WriteTo(Buffer& buf)`: バッファからデータを読み取り、文字列ストリームに書き込む。
    - `ReadFrom(Buffer& buf)`: 文字列ストリームからデータを読み取り、バッファに書き込む。
  - `FileDescriptor`: ファイルディスクリプタとの読み書きを行うクラス。
    - コンストラクタ: 読み込み用と書き込み用のファイルディスクリプタを受け取る。
    - `WriteTo(Buffer& buf)`: バッファからデータを読み取り、ファイルディスクリプタに書き込む。
    - `ReadFrom(Buffer& buf)`: ファイルディスクリプタからデータを読み取り、バッファに書き込む。

### src/io/io.cpp
- **ファイルの役割**: `include/io.h`で定義されたクラスの実装を提供します。
- **依存関係**:
  - `containers/buffer.h`: バッファ操作に関するクラスや関数を使用する。
  - `<sys/uio.h>`: `readv`システムコールを使用する。
  - `<unistd.h>`: `write`システムコールを使用する。

## クラス詳細

### Null
- **責務**: データの読み書きを行わず、バッファの可読または可書込領域を消費する。
- **公開インターフェース**:
  - `WriteTo(Buffer& buf)`: バッファの可書込領域を全て消費する。
    - 入力: `Buffer`オブジェクトへの参照
    - 出力: 消費したバイト数 (`std::size_t`)
    - 状態変化: バッファの書き込み位置が最後尾に移動する。
  - `ReadFrom(Buffer& buf)`: バッファから全てのデータを削除する。
    - 入力: `Buffer`オブジェクトへの参照
    - 出力: 削除したバイト数 (`std::size_t`)
    - 状態変化: バッファが空になる。

### StringStream
- **責務**: 文字列ストリームとの読み書きを行う。
- **公開インターフェース**:
  - コンストラクタ: 読み込み用と書き込み用の文字列ストリームを受け取る。
    - 入力: `std::istream`オブジェクトへの参照, `std::ostream`オブジェクトへの参照
    - 出力: なし
    - 状態変化: 内部で保持する読み込み用と書き込み用の文字列ストリームが設定される。
  - `WriteTo(Buffer& buf)`: バッファからデータを読み取り、文字列ストリームに書き込む。
    - 入力: `Buffer`オブジェクトへの参照
    - 出力: 書き込んだバイト数 (`std::size_t`)
    - 状態変化: バッファの読み込み位置が最後尾に移動する。文字列ストリームにデータが追加される。
  - `ReadFrom(Buffer& buf)`: 文字列ストリームからデータを読み取り、バッファに書き込む。
    - 入力: `Buffer`オブジェクトへの参照
    - 出力: 読み込んだバイト数 (`std::size_t`)
    - 状態変化: バッファにデータが追加される。文字列ストリームの読み込み位置が最後尾に移動する。

### FileDescriptor
- **責務**: ファイルディスクリプタとの読み書きを行う。
- **公開インターフェース**:
  - コンストラクタ: 読み込み用と書き込み用のファイルディスクリプタを受け取る。
    - 入力: `ws::FileDescriptor`オブジェクトへの参照, `ws::FileDescriptor`オブジェクトへの参照
    - 出力: なし
    - 状態変化: 内部で保持する読み込み用と書き込み用のファイルディスクリプタが設定される。
  - `WriteTo(Buffer& buf)`: バッファからデータを読み取り、ファイルディスクリプタに書き込む。
    - 入力: `Buffer`オブジェクトへの参照
    - 出力: 書き込んだバイト数 (`std::size_t`)
    - 状態変化: バッファの読み込み位置が最後尾に移動する。ファイルディスクリプタにデータが追加される。
  - `ReadFrom(Buffer& buf)`: ファイルディスクリプタからデータを読み取り、バッファに書き込む。
    - 入力: `Buffer`オブジェクトへの参照
    - 出力: 読み込んだバイト数 (`std::size_t`)
    - 状態変化: バッファにデータが追加される。ファイルディスクリプタの読み込み位置が最後尾に移動する。

## 例外・失敗条件
- `FileDescriptor::WriteTo(Buffer& buf)`: `readv`システムコールがエラーを返した場合、`ThrowLastSystemError()`関数を呼び出して例外を投げる。
- `FileDescriptor::ReadFrom(Buffer& buf)`: `write`システムコールがエラーを返した場合、`ThrowLastSystemError()`関数を呼び出して例外を投げる。

## 重要な不変条件
- `StringStream`と`FileDescriptor`のインスタンスは、それぞれのコンストラクタで受け取った文字列ストリームやファイルディスクリプタが有効であることを保証する必要がある。
- バッファの読み込み位置と書き込み位置は常にバッファの範囲内に存在することを保証する必要がある。

## 依存関係
- `include/io.h`:
  - `util.h`: システムエラー処理用のユーティリティ関数（`ThrowLastSystemError()`）を使用する。
  - `<iostream>`: 文字列ストリーム操作に使用する。
- `src/io/io.cpp`:
  - `containers/buffer.h`: バッファ操作に関するクラスや関数を使用する。
  - `<sys/uio.h>`: `readv`システムコールを使用する。
  - `<unistd.h>`: `write`システムコールを使用する。

## 処理手順
- **Null::WriteTo(Buffer& buf)**:
  1. バッファの可書込領域サイズを取得する。
  2. バッファの書き込み位置を最後尾に移動する。
  3. 取得したサイズを返す。

- **Null::ReadFrom(Buffer& buf)**:
  1. バッファから全てのデータを削除し、そのバイト数を取得する。
  2. 取得したサイズを返す。

- **StringStream::WriteTo(Buffer& buf)**:
  1. 文字列ストリームから文字列を読み取り、バッファに追加する。
  2. 読み取った文字列の長さを返す。

- **StringStream::ReadFrom(Buffer& buf)**:
  1. バッファから全てのデータを削除し、そのデータを文字列として取得する。
  2. 文字列ストリームに取得したデータを書き込む。
  3. 取得した文字列の長さを返す。

- **FileDescriptor::WriteTo(Buffer& buf)**:
  1. バッファから可書込領域を取得し、追加バッファを用意する。
  2. `readv`システムコールを使用してファイルディスクリプタからデータを読み取り、バッファと追加バッファに書き込む。
  3. 読み取ったバイト数を返す。エラーが発生した場合は例外を投げる。

- **FileDescriptor::ReadFrom(Buffer& buf)**:
  1. バッファから可読領域を取得する。
  2. `write`システムコールを使用してファイルディスクリプタにデータを書き込む。
  3. 書き込んだバイト数を返す。エラーが発生した場合は例外を投げる。

## 注意事項
- 文字列ストリームやファイルディスクリプタの有効性は、`StringStream`と`FileDescriptor`のインスタンス生成時に保証する必要がある。
- バッファの読み込み位置と書き込み位置が常にバッファの範囲内に存在することを保証する必要がある。
