# 設計文書: Memory クラス

## 1. 概要
この設計文書は、`Memory`クラスについての詳細な仕様を記載します。`Memory`クラスは、指定されたメモリサイズを持つ仮想的なメモリ空間を提供し、その中にデータを読み書きする機能を持っています。

## 2. 責務
- 指定されたサイズのメモリ領域を確保し初期化する。
- メモリアドレスの有効性をチェックする。
- 指定されたアドレスからワード（32ビット）やハーフワード（16ビット）、バイト（8ビット）を読み書きする。
- デバッグ用にメモリ内容を出力する。

## 3. 公開インターフェース

### 3.1 コンストラクタ
```cpp
Memory()
```
- **説明**: `Memory`オブジェクトを作成し、内部のメモリ領域をゼロで初期化します。
- **入力**: 無し
- **出力**: 無し

### 3.2 メソッド
```cpp
bool check_addr(unsigned int addr)
```
- **説明**: 指定されたアドレスが有効かどうかをチェックします。
- **入力**: `unsigned int addr` - チェックするメモリアドレス
- **出力**: `bool` - アドレスが有効な場合は`true`、それ以外は`false`

```cpp
Immediate read_word(unsigned int addr)
```
- **説明**: 指定されたアドレスからワード（32ビット）を読み取ります。
- **入力**: `unsigned int addr` - 読み取るメモリアドレス
- **出力**: `Immediate` - 読み取ったワード

```cpp
void write_word(unsigned int addr, Immediate imm)
```
- **説明**: 指定されたアドレスにワード（32ビット）を書き込みます。
- **入力**: 
  - `unsigned int addr` - 書き込むメモリアドレス
  - `Immediate imm` - 書き込むワード
- **出力**: 無し

```cpp
unsigned short read_ushort(unsigned int addr)
```
- **説明**: 指定されたアドレスからハーフワード（16ビット）を読み取ります。
- **入力**: `unsigned int addr` - 読み取るメモリアドレス
- **出力**: `unsigned short` - 読み取ったハーフワード

```cpp
void write_ushort(unsigned int addr, unsigned short imm)
```
- **説明**: 指定されたアドレスにハーフワード（16ビット）を書き込みます。
- **入力**: 
  - `unsigned int addr` - 書き込むメモリアドレス
  - `unsigned short imm` - 書き込むハーフワード
- **出力**: 無し

```cpp
unsigned char &operator[](unsigned int addr)
```
- **説明**: 指定されたアドレスのバイト（8ビット）への参照を返します。
- **入力**: `unsigned int addr` - アクセスするメモリアドレス
- **出力**: `unsigned char &` - アドレスに対応するバイトへの参照

```cpp
void debug()
```
- **説明**: デバッグ用に一部のメモリ内容を標準出力に出力します。
- **入力**: 無し
- **出力**: 無し

## 4. 入力
- `unsigned int addr` - メモリアドレス（読み書き操作で使用）
- `Immediate imm` - 書き込むワード（32ビット）
- `unsigned short imm` - 書き込むハーフワード（16ビット）

## 5. 出力
- `bool` - アドレスの有効性チェック結果
- `Immediate` - 読み取ったワード（32ビット）
- `unsigned short` - 読み取ったハーフワード（16ビット）
- `unsigned char &` - メモリアドレスに対応するバイトへの参照

## 6. 状態
- `unsigned char mem[MEMORY_SIZE]` - メモリ領域
- `unsigned char placeholder` - アドレスチェックに失敗した場合のダミーバイト

## 7. 処理手順
1. **コンストラクタ呼び出し**:
   - 内部メモリ領域をゼロで初期化する。

2. **アドレスチェック (`check_addr`)**:
   - 指定されたアドレスが有効範囲内であるか確認する。
   
3. **ワード読み取り (`read_word`)**:
   - アドレスチェックを行い、有効な場合は指定されたアドレスからワードを読み取る。

4. **ワード書き込み (`write_word`)**:
   - アドレスチェックを行い、有効な場合は指定されたアドレスにワードを書き込む。
   
5. **ハーフワード読み取り (`read_ushort`)**:
   - アドレスチェックを行い、有効な場合は指定されたアドレスからハーフワードを読み取る。

6. **ハーフワード書き込み (`write_ushort`)**:
   - アドレスチェックを行い、有効な場合は指定されたアドレスにハーフワードを書き込む。
   
7. **バイトアクセス (`operator[]`)**:
   - アドレスチェックを行い、有効な場合は指定されたアドレスのバイトへの参照を返す。

8. **デバッグ出力 (`debug`)**:
   - 指定された範囲のメモリ内容を標準出力に出力する。

## 8. 例外・失敗条件
- `check_addr`が`false`を返した場合、アドレスチェックに失敗し、読み書き操作は行われない。
- アドレスチェックに失敗した場合は、`read_word`, `write_word`, `read_ushort`, `write_ushort`はデフォルト値（0）を返すか何もしない。

## 9. 依存関係
- `Common.h`: システム全体の共通定義やマクロが含まれている。
- `<cstring>`: `memset`関数を使用するためのヘッダファイル。
- `<iostream>`: デバッグ出力用の標準入出力ストリームを提供するヘッダファイル。
- `<cassert>`: アサーション機能を使用するためのヘッダファイル。

## 10. 重要な不変条件
- `mem`配列は常に`MEMORY_SIZE`（0x400000）バイトの大きさを持つこと。
- `placeholder`は常に初期化され、アドレスチェックに失敗した場合のデフォルト値として使用されること。
