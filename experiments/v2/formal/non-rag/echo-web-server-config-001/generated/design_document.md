# 設計文書: config モジュール

## 概要
このモジュールは、YAML形式の設定ファイルを読み込み、管理するための機能を提供します。主なクラスとして `Var`（設定変数）と `Config`（設定全体）が定義されており、これらのクラスを通じて設定値の取得・設定や変更イベントへのリスナー登録などが可能となります。

## ファイル構造

### include/config.h
- **責務**: 設定管理に関連するクラスとテンプレートを宣言します。
- **公開インターフェース**:
  - `VarConverter`: 値の型変換を行うためのテンプレートクラス群。
  - `VarBase`: 設定変数の基底クラス。
  - `Var<T>`: 具体的な設定変数を表すクラス。`T`は任意のデータ型です。
  - `Config`: 複数の設定変数を管理するクラス。
- **入力**: YAML形式の文字列や値。
- **出力**: 文字列形式の設定値、または特定の型の値。
- **状態**: 各設定変数の値とその変更イベントリスナー。
- **処理手順**:
  - `VarConverter`: 値を指定された型に変換します。
  - `VarBase`: 設定変数の基本的な情報を提供します。
  - `Var<T>`: 値の取得・設定と変更イベントへのリスナー登録を行います。
  - `Config`: 設定変数を管理し、YAML形式から値を読み込みます。
- **例外・失敗条件**:
  - `std::invalid_argument`: YAMLノードが期待する型でない場合や、設定変数の型が一致しない場合にスローされます。
- **依存関係**: `util.h`, `YAML`ライブラリ, `fmt`ライブラリ
- **重要な不変条件**:
  - `Var<T>`: 値の取得と設定はスレッドセーフです。
  - `Config`: 設定変数の追加・削除や値の読み込みもスレッドセーフです。

### src/config/config.cpp
- **責務**: `config.h`で宣言されたクラスの実装を提供します。
- **公開インターフェース**:
  - `VarBase`: コンストラクタ、名前と説明の取得メソッド。
  - `Config`: コンストラクタ、設定変数の検索・追加、YAMLノードからの値読み込み、設定変数への訪問。
- **入力**: YAML形式のノードや値。
- **出力**: 設定変数のポインタやその他の情報。
- **状態**: 各設定変数のマップとロックオブジェクト。
- **処理手順**:
  - `VarBase`: コンストラクタで名前と説明を初期化します。
  - `Config`: YAMLノードから値を読み込み、既存の設定変数に適用します。また、設定変数へのアクセスはスレッドセーフに行われます。
- **例外・失敗条件**:
  - `std::invalid_argument`: YAMLノードが期待する型でない場合や、設定変数の型が一致しない場合にスローされます。
- **依存関係**: `config.h`, `YAML`ライブラリ, `fmt`ライブラリ
- **重要な不変条件**:
  - `Config`: 設定変数へのアクセスはスレッドセーフです。

## ファイル間の関係
- `include/config.h`は、設定管理に関連するクラスとテンプレートを宣言します。
- `src/config/config.cpp`は、これらのクラスの実装を提供します。これにより、設定ファイルの読み込みや変数の操作が可能となります。

## 重要な点
- このモジュールではスレッドセーフな設計が行われており、複数のスレッドからのアクセスに対応しています。
- YAML形式の設定ファイルから値を読み込むため、`YAML`ライブラリが必要です。また、エラーメッセージのフォーマットには`fmt`ライブラリを使用しています。

## 依存関係
- `util.h`: 未定義のユーティリティクラスや関数を含む可能性があります。
- `YAML`ライブラリ: YAML形式のデータを処理するために必要です。
- `fmt`ライブラリ: エラーメッセージのフォーマットに使用されます。
