# デザイン文書: Parser クラス

## 責務
`Parser`クラスは、入力ストリームからデータを読み取り、それを指定されたメモリオブジェクトに書き込む責任を持っています。具体的には、16進数形式のデータをパースし、メモリアドレスに対して適切な値を設定します。

## 公開インターフェース
- `static unsigned parse_hex(const std::string &hex)`
  - 機能: 16進数文字列を符号なし整数に変換する。
  - 引数: 
    - `const std::string &hex`: 変換したい16進数形式の文字列。
  - 戻り値: 変換された符号なし整数。

- `static void parse(std::istream &in, Memory &mem)`
  - 機能: 入力ストリームからデータを読み取り、それをメモリオブジェクトに書き込む。入力はアドレス指定とデータのペアで構成される。
  - 引数:
    - `std::istream &in`: パースしたいデータが含まれる入力ストリーム。
    - `Memory &mem`: データを書き込むメモリオブジェクト。

- `static void parse_hex(std::istream &in, Memory &mem)`
  - 機能: 入力ストリームから16進数形式のワードデータを読み取り、それをメモリオブジェクトに書き込む。
  - 引数:
    - `std::istream &in`: パースしたいデータが含まれる入力ストリーム。
    - `Memory &mem`: データを書き込むメモリオブジェクト。

## 入力
- `parse_hex`:
  - 文字列形式の16進数値。
- `parse`:
  - 各行がアドレス指定(`@`)またはデータ(16進数)である入力ストリーム。
- `parse_hex`:
  - 各単語が16進数ワードである入力ストリーム。

## 出力
- メモリオブジェクトへの書き込み。

## 状態
- 内部状態は保持されず、すべてのメソッドが静的であり独立しています。
- `parse`と`parse_hex`メソッドでは一時的な変数(`base_addr`, `line`, `hex`)を使用しますが、これらはローカルスコープに限定されます。

## 処理手順
### parse_hex
1. 入力ストリームから16進数文字列を読み取ります。
2. 読み取った文字列を`parse_hex`メソッドで符号なし整数に変換します。
3. 変換した値を指定されたメモリオブジェクトの現在のベースアドレスに書き込みます。
4. ベースアドレスを4バイト(ワードサイズ)増加させ、次のデータの書き込み位置を設定します。

### parse
1. 入力ストリームから一行ずつ読み取ります。
2. 行が`@`で始まる場合:
   - `@`以降の文字列をベースアドレスとしてパースし、現在のベースアドレスを更新します。
3. 行がデータである場合:
   - スペース区切りで16進数文字列を読み取ります。
   - 各16進数文字列を`parse_hex`メソッドで符号なし整数に変換し、それを現在のベースアドレスに書き込みます。
   - ベースアドレスを1バイト増加させ、次のデータの書き込み位置を設定します。

## 例外・失敗条件
- 入力ストリームが無効な場合(`!in`が真の場合):
  - エラーメッセージを標準エラー出力に出力し、処理を継続せずに終了します。
- パースできないデータが含まれる場合:
  - `strtol`関数の動作により未定義動作となる可能性があります。ただし、具体的なエラーハンドリングは行われていません。

## 依存関係
- `Memory`: データを書き込むためのメモリオブジェクト。
- 標準ライブラリ: 入出力ストリーム操作(`std::istream`, `std::stringstream`), 文字列操作(`std::string`), 数値変換(`strtol`)。

## 重要な不変条件
- メモリオブジェクトへの書き込みは、入力データに基づいて行われるため、メモリの初期状態は保証されません。
- `parse_hex`と`parse`メソッドは静的であり、インスタンス間で共有される内部状態はありません。
