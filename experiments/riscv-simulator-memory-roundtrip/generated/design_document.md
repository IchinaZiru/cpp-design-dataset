# デザイン文書

## クラス: Memory

### 責務
- 固定サイズのメモリ空間を提供し、その読み書き操作を行う。
- アドレス範囲チェックを行い、不正なアクセスを防ぐ。

### 公開インターフェース
| 関数名          | 説明                                                                 |
|-------------------|----------------------------------------------------------------------|
| `Memory()`        | メモリ空間をゼロクリアして初期化する。                             |
| `check_addr`      | 指定されたアドレスが有効範囲内であるかチェックする。               |
| `read_word`       | 指定されたアドレスから `Immediate` 型の値を読み込む。             |
| `write_word`      | 指定されたアドレスに `Immediate` 型の値を書き込む。              |
| `read_ushort`     | 指定されたアドレスから `unsigned short` 型の値を読み込む。       |
| `write_ushort`    | 指定されたアドレスに `unsigned short` 型の値を書き込む。        |
| `operator[]`      | 指定されたアドレスに対応するメモリ位置への参照を返す。           |
| `debug`           | メモリの特定範囲をデバッグ出力として表示する。                   |

### 入力
- `unsigned int addr`: アクセスしたいメモリのアドレス。
- `Immediate imm`: 書き込む `Immediate` 型の値。
- `unsigned short imm`: 書き込む `unsigned short` 型の値。

### 出力
- `bool`: アドレスが有効かどうかを示す真偽値。
- `Immediate`: 指定されたアドレスから読み込んだ `Immediate` 値。
- `unsigned short`: 指定されたアドレスから読み込んだ `unsigned short` 値。
- `unsigned char &`: 指定されたアドレスに対応するメモリ位置への参照。

### 状態
- `mem[MEMORY_SIZE]`: メモリ空間を表す配列。
- `placeholder`: アドレス範囲外アクセス時に返されるダミー値。

### 処理手順
1. **初期化 (`Memory()`)**:
   - メモリ空間 `mem` をゼロクリアする。

2. **アドレスチェック (`check_addr`)**:
   - 指定されたアドレスが 0 以上 `MEMORY_SIZE` 未満であるかを確認する。
   - アドレスが範囲外の場合は `false`、範囲内の場合は `true` を返す。

3. **ワード読み込み (`read_word`)**:
   - 指定されたアドレスが有効であることを確認する。
   - アドレスが無効な場合は 0 を返す。
   - アドレスが有効な場合は、指定されたアドレスから `Immediate` 型の値を読み込んで返す。

4. **ワード書き込み (`write_word`)**:
   - 指定されたアドレスが有効であることを確認する。
   - アドレスが無効な場合は何もせずに終了する。
   - アドレスが有効な場合は、指定されたアドレスに `Immediate` 型の値を書き込む。

5. **アンサインショート読み込み (`read_ushort`)**:
   - 指定されたアドレスが有効であることを確認する。
   - アドレスが無効な場合は 0 を返す。
   - アドレスが有効な場合は、指定されたアドレスから `unsigned short` 型の値を読み込んで返す。

6. **アンサインショート書き込み (`write_ushort`)**:
   - 指定されたアドレスが有効であることを確認する。
   - アドレスが無効な場合は何もせずに終了する。
   - アドレスが有効な場合は、指定されたアドレスに `unsigned short` 型の値を書き込む。

7. **インデックスアクセス (`operator[]`)**:
   - 指定されたアドレスが有効であることを確認する。
   - アドレスが無効な場合は `placeholder` を返す。
   - アドレスが有効な場合は、指定されたアドレスに対応するメモリ位置への参照を返す。

8. **デバッグ出力 (`debug`)**:
   - メモリの特定範囲 (0x1FF90 から 0x20000) を 16進数形式で表示する。

### 例外・失敗条件
- アドレスが `MEMORY_SIZE` の範囲外の場合、読み書き操作は無視され、適切な値 (0 や `placeholder`) が返される。
- アドレスチェックに失敗した場合、アサートが発生する可能性がある（現在のコードではコメントアウトされている）。

### 依存関係
- `Immediate`: この型は定義されていないため、外部で定義されていると仮定する。
- `<cstring>`: `memset` 関数を使用している。
- `<iostream>`: デバッグ出力用の `std::cout` を使用している。

### 重要な不変条件
- `mem` のサイズは常に `MEMORY_SIZE` である。
- アドレス範囲チェックはすべての読み書き操作で行われる。
