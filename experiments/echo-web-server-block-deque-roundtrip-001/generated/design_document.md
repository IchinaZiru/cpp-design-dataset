# デザイン文書: `BlockDeque` クラス

## 概要
この設計文書は、`block-deque` モジュールの主要なクラスである `BlockDeque` を詳細に記述します。このクラスは、スレッドセーフなブロックデキュー（両端キュー）を実装しており、最大容量を超えた場合や空の場合にスレッドが待つ機能を持っています。

## 責務
- スレッドセーフな双方向キューの提供。
- キューへの要素の追加と削除操作。
- キューの状態（空、満杯）の確認。
- キューのクリアおよびクローズ機能。

## 公開インターフェース

| メソッド名 | 説明 |
| --- | --- |
| `BlockDeque(std::size_t capacity)` | コンストラクタ。最大容量を指定して初期化します。 |
| `~BlockDeque()` | デストラクタ。キューをクローズし、リソースを解放します。 |
| `void Clear() noexcept` | キュー内のすべての要素をクリアします。 |
| `bool Empty() const noexcept` | キューが空であるかどうかを返します。 |
| `bool Full() const noexcept` | キューが満杯であるかどうかを返します。 |
| `std::size_t Size() const noexcept` | キュー内の要素数を返します。 |
| `std::size_t Capacity() const noexcept` | キューの最大容量を返します。 |
| `void PushBack(T item) noexcept` | 要素をキューの末尾に追加し、消費者スレッドに通知します。 |
| `void PushFront(T item) noexcept` | 要素をキューの先頭に挿入し、消費者スレッドに通知します。 |
| `const T& Front() const noexcept` | キューの最初の要素への参照を返します（キューが空でないことを保証）。 |
| `const T& Back() const noexcept` | キューの最後の要素への参照を返します（キューが空でないことを保証）。 |
| `T& Front() noexcept` | キューの最初の要素への非定数参照を返します（キューが空でないことを保証）。 |
| `T& Back() noexcept` | キューの最後の要素への非定数参照を返します（キューが空でないことを保証）。 |
| `std::optional<T> Pop(std::optional<Clock::duration> time_out = std::nullopt) noexcept` | キューから最初の要素を取り出し、それを返します。タイムアウトやクローズ状態により取り出せない場合は `std::nullopt` を返します。 |
| `void Flush() noexcept` | 消費者スレッドに通知します。 |
| `void Close() noexcept` | キュー内のすべての要素をクリアし、キューをクローズします。 |

## 入力
- コンストラクタ: 最大容量（`std::size_t capacity`）。
- `PushBack`, `PushFront`: 追加または挿入する要素（`T item`）。
- `Pop`: オプションのタイムアウト値（`std::optional<Clock::duration> time_out`）。

## 出力
- `Empty`, `Full`: ブーリアン値を返します。
- `Size`, `Capacity`: 要素数や最大容量を表す `std::size_t` 値を返します。
- `Front`, `Back`: キューの先頭または末尾の要素への参照を返します。
- `Pop`: 取り出した要素（`T`）を含む `std::optional<T>` を返します。

## 状態
- `mtx_`: ミューテックス。スレッドセーフな操作のために使用されます。
- `closed_`: キューがクローズされているかどうかを示すブール値。
- `capacity_`: キューの最大容量。
- `deq_`: 実際のデータを保持するデキュー（`std::deque<T>`）。
- `consumer_cond_`, `producer_cond_`: コンシューマーとプロデューサーの間で同期を行うための条件変数。

## 処理手順
1. **コンストラクタ**: 最大容量を設定し、内部データ構造を初期化します。
2. **デストラクタ**: キューをクローズしてリソースを解放します。
3. **Clear**: ミューテックスで保護されたクリア操作を行います。
4. **Empty, Full, Size, Capacity**: 状態を確認するための読み取り操作を行います。
5. **PushBack, PushFront**: 要素を追加または挿入し、必要に応じて消費者スレッドに通知します。
6. **Front, Back**: キューの先頭または末尾の要素への参照を返します。キューが空でないことを保証します。
7. **Pop**: オプションのタイムアウト値を使用して、最初の要素を取り出し、それを返します。クローズ状態やタイムアウトにより取り出せない場合は `std::nullopt` を返します。
8. **Flush**: 消費者スレッドに通知します。
9. **Close**: キュー内のすべての要素をクリアし、キューをクローズしてプロデューサーと消費者スレッドに通知します。

## 例外・失敗条件
- `PushBack`, `PushFront`: キューが満杯の場合、呼び出し元スレッドはブロックされます。
- `Pop`: タイムアウトにより要素を取り出せない場合やキューがクローズされている場合は `std::nullopt` を返します。

## 依存関係
- `<cassert>`: アサーションのため。
- `<condition_variable>`: スレッド間同期のため。
- `<deque>`: データを保持するため。
- `<mutex>`: スレッドセーフな操作のために使用されるミューテックス。
- `<optional>`: オプション値の扱いに使用されます。
- `<utility>`: 一部のユーティリティ関数や型を使用します。

## 重要な不変条件
- `capacity_` は常に正である。
- `deq_.size()` は常に `capacity_` よりも小さいか等しい。
- `closed_` が `true` の場合、新たな要素の追加は行われず、既存の要素を取り出すことはできません。
