# Generic detailed-design guidance

# 汎用詳細設計知識 v4

## 目的

対象コードから、再実装に必要な実装上の事実を失わない詳細設計情報を生成する。
v3のクラス図・インターフェース詳細・シーケンス図・メソッド仕様・処理フロー・状態遷移・データ変換の観点は維持するが、単なる情報量の増加ではなく、再生成に必要な正確性を優先する。

## 共通記述規則

- 元コードと与えられた文脈から確認できる事実だけを記述する。
- 元コードにない機能、API、型、状態、初期値、例外、依存関係、制約を推測で追加しない。
- 確認できない情報は推測せず「確認不能」と記述する。
- ソースコード全文を複製しない。再実装に必要な事実を、表、短い式、疑似コード、図、自然言語へ変換して記述する。
- 識別子、型名、関数名、メソッド名、メンバ名、定数名、条件、演算子、数値は、再実装結果に影響する場合は元コードの表記と意味を保つ。
- 同じsymbolを複数の表・図で記述する場合、型、可視性、const、副作用、呼び出し先、状態更新を互いに矛盾させない。矛盾が生じる場合は元コードで確認できる事実を正とする。
- 対象に該当しない成果物は「該当なし」と簡潔な根拠を記述する。
- 図はMarkdown内のMermaidで記述することを推奨するが、図の形式より設計内容の正確性を優先する。

## 再実装忠実度の必須観点

### 1. 正確な定義

再実装に影響する `using`、`typedef`、`enum`、`concept`、`requires`、macro、定数、nested/base class、構造体フィールドについて、確認できる場合は名前だけでなく実体・値・構造を記述する。

ソース全文の引用は不要であり、例えば型別名は「型名 / 種別 / 実体」の表として記述してよい。

### 2. 直接依存インターフェースと利用方法

対象が直接利用する関数・メソッド・型について、確認できる範囲で以下を記述する。

- qualified name / namespace
- 引数名と型
- 戻り値型
- `const`、`noexcept`、`static`、`virtual`
- 参照・ポインタの区別
- 実際に渡す値や型変換
- 戻り値の消費方法
- 呼び出し順序

「Loggerを使う」「Memoryへ書く」のような抽象的記述だけで終わらせず、元コードから確認できる場合はどのAPIをどのように利用するかまで設計情報として残す。

### 3. 結果を決める式・具体値

次のような値や式が実装結果を決める場合、自然言語へ丸めず正確に保持する。

- 条件式、比較演算子、switch case
- bit位置、bit幅、mask、shift量、符号拡張
- byte数、サイズ単位、長さ制約
- 配列index、offset、アドレス増分
- loop境界、増分値
- literal、sentinel、default値、error code
- 文字列・改行・encodingなどの変換規則

関数本体全体を貼る必要はなく、表や短い式、疑似コードとして記述してよい。

### 4. 使用データ・更新データ

処理が参照・更新するデータについて、再実装に必要であれば具体的なアクセス対象を記述する。

- `object.member.submember` のような参照先
- 入力 / 出力 / 内部状態の区別
- 初期値と更新後の値
- 更新条件と更新順序
- コピー元 / コピー先
- データの所有権・寿命

### 5. 状態・副作用・不変条件

状態更新、所有権、寿命、lock範囲、wait predicate、notify、close、error contractなど、動作の正当性に必要な制約を記述する。

「副作用なし」と記述する場合は、メンバ・外部資源・出力引数・ログ・I/Oの変更が本当にないことを元コードから確認する。

## クラス図

クラス、構造体、インターフェース相当の型が対象または対象に直接関係する場合、クラス・構造体、属性、主要メソッド、継承、所有・参照・直接依存関係を表す。
可視性や型を推測で補正しない。

## クラス・メソッド・インターフェース詳細

対象のクラス、構造体、関数、メソッドについて、再実装に必要なインターフェース情報を表形式で記述する。
完全な名前、属性、引数名と型、戻り値型、可視性、`const`、参照、ポインタ、`static`、`virtual`、`noexcept`、型別名、列挙型、定数、直接依存を確認できる範囲で含める。

## シーケンス図

複数の関数、メソッド、オブジェクト間の相互作用を元コードから確認できる場合、呼び出し順序、受け渡す値、戻り値の利用、条件分岐、状態変更、エラー経路を表す。
確認できない応答や呼び出しを創作しない。

## メソッド仕様書

対象関数または主要メソッドについて、目的、引数、戻り値、動作、副作用、エラー処理、必要に応じて前提条件、事後条件、境界条件、不変条件を記述する。
実際の利用方法を確認できる場合は短い利用例を記述し、確認できない場合は「確認不能」とする。

## 処理フロー図

主要処理について、分岐、反復、早期終了、主要な呼び出し、状態更新、処理順序を表す。
条件や具体値が結果を左右する場合は、抽象的な「条件判定」だけでなく、その条件を識別可能な形で残す。

## 状態遷移・副作用

状態を保持または変更する処理について、更新前状態、遷移条件、変更対象、更新後状態、更新順序、外部資源への副作用を表形式で記述する。
リソース取得・解放、並行処理上の制約、所有・寿命が存在する場合は、それらも確認できる範囲で記述する。

## データ変換・制約

入力から出力への変換、型変換、加工規則、値域、境界値、単位、精度、encoding、検証条件、特殊値・欠損値の扱いを表形式で記述する。
bit幅、符号、byte数、index、offset、アドレス増分など、再実装結果を左右する具体値は正確に保持する。

class Event {
public:
    using Ptr = std::shared_ptr<Event>;

    using Clock = std::chrono::system_clock;

    /**
     * @brief Create an event.
     *
     * @param level The event level.
     * @param location The event location.

     * @todo Replace @p std::experimental::source_location with @p std::source_location.

                      std::uint32_t thread_id = CurrentThreadId(),

    Clock::time_point Time() const noexcept;

                   std::uint32_t thread_id, Clock::time_point time) noexcept;

    log::Level level_;
    std::string_view file_name_;
    std::size_t line_num_;
    std::uint32_t thread_id_;
    Clock::time_point time_;

    std::ostringstream msg_;
};

//! The event formatter.
class Formatter {
public:
    using Ptr = std::shared_ptr<Formatter>;

    static Formatter::Ptr Default() noexcept;

    /**
     * @brief
     * The field formatter for different information.
     * A formatter usually needs multiple field formatters, such as for thread ID and time.
     *
     * @see src/log/field.h
     */
    class Field {
    public:
        using Ptr = std::shared_ptr<Field>;

        /**
         * @brief Create a field formatter.
         *
         * @param format An optional format required for some fields.
         */
        explicit Field(std::string_view format = "") noexcept;

        virtual ~Field() noexcept = default;

        //! Format a field into a string.
        virtual void Format(std::ostream& out, const Logger& logger,
                            const Event& event) noexcept = 0;

        /**
         * @brief
         * Get the tag representing a field.
         * The tag does not contain the preceding symbol @p %.
         */
        virtual std::string_view Tag() const noexcept = 0;
    };

    /**
     * @brief Create a formatter.
     *
     * @param pattern A format pattern, consisting of multiple fields and their format.
     *
     * @exception std::invalid_argument The pattern is invalid.
     */
    explicit Formatter(std::string_view pattern);

    //! Format an event into a string.
    std::string Format(const Logger& logger, const Event& event) const noexcept;

    std::string_view Pattern() const noexcept;

private:
    std::string pattern_;
    std::list<Field::Ptr> fields_;
};

/**
 * @brief The singleton pattern interface for references.
 *
 * @tparam T A type using the singleton pattern.
 * @tparam Args The arguments of the singleton instance, referring to one of its constructors.
 */
template <typename T, typename... Args>
class Singleton {
public:
    /**
     * @brief Get the singleton instance.
     *
     * @tparam args The construction arguments.
     */
    template <Args... args>
    static T& Instance() noexcept {
        static T ins {std::move(args)...};
        return ins;
    }
};

/**
 * @brief The singleton pattern interface for smart points.
 *
 * @tparam T A type using the singleton pattern.
 * @tparam Args The argument types of the singleton instance, referring to one of its constructors.
 */
template <typename T, typename... Args>
class SingletonPtr {
public:
    /**
     * @brief Get the singleton instance.
     *
     * @tparam args The construction arguments.
     */
    template <Args... args>
    static std::shared_ptr<T> Instance() noexcept {
        static const std::shared_ptr<T> ins {
            std::make_shared<T>(std::move(args)...)};
        return ins;
    }
};

template <typename T, typename Cleaner = std::function<void(T)>>
requires std::is_invocable_v<Cleaner, T>
class RAII {
public:
    /**
     * @brief Create a RAII for an object.
     *
     * @param obj An object needing to be cleaned.
     * @param cleaner A cleaner.
     */
    explicit RAII(T obj, Cleaner cleaner) noexcept :
        obj_ {std::move(obj)}, cleaner_ {std::move(cleaner)} {}

    RAII(const RAII&) = delete;

    RAII(RAII&&) = delete;

    RAII& operator=(const RAII&) = delete;

    RAII& operator=(RAII&&) = delete;

    ~RAII() noexcept {
        cleaner_(obj_);
    }

    const T& Object() const noexcept {
        return obj_;
    }

private:
    T obj_;
    Cleaner cleaner_;
};

/**
 * @brief
 * RAII for a read-only file that has been mapped into memory.
 *
 * @details
 * It encapsulates @p stat, @p mmap and @p munmap of Linux system.
 */
class MappedReadOnlyFile {
public:
    MappedReadOnlyFile() noexcept;

    MappedReadOnlyFile(const MappedReadOnlyFile&) = delete;

    MappedReadOnlyFile(MappedReadOnlyFile&&) noexcept;

    MappedReadOnlyFile& operator=(const MappedReadOnlyFile&) = delete;

    MappedReadOnlyFile& operator=(MappedReadOnlyFile&&) noexcept;

    ~MappedReadOnlyFile() noexcept;

    /**
     * @brief Map a file into memory.
     *
     * @exception std::invalid_argument The path refers to a directory.
     * @exception std::runtime_error No permission to access the file.
     * @exception std::system_error Failed to map the file.
     */
    std::byte* Map(std::string path);

    //! Unmap the file.
    void Unmap() noexcept;

    //! Get the file size.
    std::size_t Size() const noexcept;

    //! Get the file data.
    std::byte* Data() const noexcept;

    //! Get the file path.
    std::string_view Path() const noexcept;

private:
    /**
     * @brief Check the file.
     *
     * @exception std::invalid_argument The path refers to a directory.
     * @exception std::runtime_error No permission to access the file.
     * @exception std::system_error Other system errors.
     */
    void Check();

    std::string path_;
    struct stat stat_ {};
    std::byte* data_ {nullptr};
};
