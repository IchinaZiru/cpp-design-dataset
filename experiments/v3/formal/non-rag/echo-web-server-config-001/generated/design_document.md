## 責務
- `config.h`と`config.cpp`は、YAML形式の設定ファイルを読み取り、内部データ構造に変換し、その値を管理するためのモジュールです。
- `VarConverter`クラス群は、異なる型間での変換機能を提供します。
- `VarBase`と`Var`クラスは、設定変数の基本情報と具体的な値を保持し、それらに対する操作（読み取り、書き込み）を行います。
- `Config`クラスは、複数の設定変数を管理し、YAMLノードから設定値を読み込む機能を持っています。

## 公開インターフェース
- `VarConverter<From, To>`: 任意の型間での変換を行うためのテンプレートクラス。
- `VarBase`: 設定変数の基本情報を保持する基底クラス。`Name()`, `Description()`, `ToString()`, `FromString()`を公開しています。
- `Var<T>`: 具体的な設定値を保持し操作する派生クラス。`GetValue()`, `SetValue()`, `TypeName()`, `AddListener()`, `RemoveListener()`, `ClearListeners()`を公開しています。
- `Config`: 設定変数のコレクションを管理します。`Lookup<T>()`, `LoadYaml()`, `Visit()`を公開しています。
- `RootConfig()`: ルート設定インスタンスへのアクセスを提供する関数。

## 入力
- YAML形式の設定データ（文字列またはノード）。
- 設定変数名とそのデフォルト値、説明文。
- 値変更時のコールバックリスナー。

## 出力
- `VarBase`や`Var<T>`インスタンスを通じて設定値の読み取りと書き込みが可能。
- YAMLノードから読み込んだ設定値を内部データ構造に反映。
- 設定変数のリストに対して任意の関数オブジェクトを適用（Visitメソッド）。

## 状態
- `VarBase`: 名前、説明文が保持される。
- `Var<T>`: 値とリスナーのマップが保持される。値はスレッドセーフにアクセス可能。
- `Config`: 設定変数名をキーとした設定変数へのポインタのマップが保持される。

## 処理手順
1. **VarConverter**: テンプレート特殊化により、異なる型間での変換処理を行う。
2. **VarBase**: 名前と説明文を初期化し、派生クラスで値の読み書きメソッドを定義する。
3. **Var<T>**: 値の取得・設定を行い、リスナーに通知。型変換は`VarConverter`を使用する。
4. **Config**: 設定変数の検索と追加、YAMLノードからの値読み込み、設定変数への関数適用を行う。

## 例外・失敗条件
- `VarConverter`: 変換に失敗した場合（例：文字列から数値への変換失敗）`std::invalid_argument`をスローする。
- `Config::Lookup<T>()`: 見つかった設定変数の型が要求された型と一致しない場合、`std::invalid_argument`をスローする。

## 依存関係
- YAMLパーサー（YAMLライブラリ）
- fmtライブラリ（フォーマット化用）

## 重要な不変条件
- `Var<T>`: 値の設定時に古い値と新しい値が異なる場合のみ、リスナーに通知される。
- `Config`: 同じ名前の設定変数は一度しか追加されない。
