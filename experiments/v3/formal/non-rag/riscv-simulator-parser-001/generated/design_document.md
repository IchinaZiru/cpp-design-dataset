# 基本設計項目の出力構成（全条件共通・固定）

## 責務
`Parser` クラスは、入力ストリームからデータを読み取り、それをメモリオブジェクトに書き込む責任を持っています。具体的には、16進数形式のデータをパースし、指定されたアドレスに格納します。

## 公開インターフェース
- `static unsigned parse_hex(const std::string &hex)`: 16進数文字列を符号なし整数に変換します。
- `static void parse(std::istream &in, Memory &mem)`: 入力ストリームからデータを読み取り、メモリオブジェクトにバイト単位で書き込みます。アドレスは`@`で指定された値から始まります。
- `static void parse_hex(std::istream &in, Memory &mem)`: 入力ストリームから16進数のワード（4バイト）を読み取り、メモリオブジェクトに書き込みます。アドレスは自動的にインクリメントされます。

## 入力
- `parse_hex` メソッド: 16進数文字列。
- `parse` メソッド: 行単位の入力ストリーム、各行にはデータまたはベースアドレスが含まれています。データ行はスペース区切りの16進数値で構成され、ベースアドレス行は`@`で始まる16進数値です。
- `parse_hex` メソッド: スペース区切りの16進数ワード。

## 出力
- なし（メモリオブジェクトへの書き込み）

## 状態
- 内部状態は保持されず、すべての操作が静的メソッドとして実装されています。
- `parse` メソッド: `base_addr` 変数を使用して現在の書き込み位置を追跡します。

## 処理手順
1. **parse_hex**:
   - 入力ストリームから16進数文字列を読み取ります。
   - その文字列を整数に変換し、メモリオブジェクトの現在のアドレス位置に書き込みます。
   - アドレスは4バイトずつインクリメントされます。

2. **parse**:
   - 入力ストリームから行を読み取ります。
   - 行が`@`で始まる場合、その16進数値をベースアドレスとして設定します。
   - それ以外の場合は、スペース区切りの16進数文字列を読み取り、それぞれを整数に変換し、メモリオブジェクトの現在のアドレス位置に書き込みます。アドレスは1バイトずつインクリメントされます。

## 例外・失敗条件
- 入力ストリームが無効な場合（`if (!in)`）、エラーメッセージを出力します。
- `parse_hex` メソッド: 不正な16進数文字列が入力された場合、未定義の動作となる可能性があります。

## 依存関係
- `Memory` クラス: データの書き込み先として使用されます。このクラスは別途定義されている必要があります。
- 標準ライブラリ: `<iostream>`, `<iomanip>`, `<sstream>`, `<string>` を使用しています。

## 重要な不変条件
- `parse_hex` メソッド: 入力ストリームが有効であることを確認します。
- `parse` メソッド: 同じく入力ストリームの有効性を確認し、ベースアドレスは正しい16進数形式である必要があります。
