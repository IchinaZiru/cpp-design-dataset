## 責務
`Session`クラスはRISC-Vシミュレータのセッションを管理します。メモリの読み込み、サイクルの進行（tick）、デバッグ情報の出力、レポートの生成などの機能を持っています。

## 公開インターフェース
- `Session(bool debug = false);` : セッションオブジェクトを初期化します。
- `void tick();` : シミュレーションの1サイクルを進めます。
- `void load_memory(const char *path);` : メモリにファイルからデータを読み込みます。
- `void load_memory(std::istream &in);` : ストリームからメモリにデータを読み込みます。
- `void load_hex(const char *path);` : 16進数形式のファイルからメモリにデータを読み込みます。
- `void report(std::ostream& out);` : シミュレーションレポートを出力します。
- `virtual ~Session();` : セッションオブジェクトを破棄します。

## 入力
- メモリへのデータの読み込みに使用されるファイルパスやストリーム。
- オプションとしてデバッグフラグ（`bool debug`）。

## 出力
- `tick()`メソッドを通じてシミュレーションの進行状況。
- `report(std::ostream& out)`メソッドを通じてレポート出力。

## 状態
- `_debug`: デバッグモードを示すブール値。
- `rf`: レジスタファイルオブジェクト。
- `memory`: メモリオブジェクト。
- `e`: 出力オーオーライナーエグゼキュートオブジェクトへのポインタ。
- `i`: イシューステージオブジェクトへのポインタ。
- `branch`: ブランチ予測オブジェクトへのポインタ。
- `stat`: シミュレーションの統計情報（現在のサイクル数）。

## 処理手順
1. **初期化**:
   - コンストラクタで`Issue`, `OoOExecute`, `BranchPrediction`オブジェクトを生成し、メンバ変数に格納します。
2. **メモリ読み込み**:
   - ファイルパスやストリームからデータを読み込み、`Memory`オブジェクトに格納します。
3. **サイクル進行**:
   - `tick()`メソッドで各ステージ（イシュー、エグゼキュート）の更新と進行情報を処理し、サイクルカウンタをインクリメントします。
4. **デバッグ情報出力**:
   - `_debug`が真の場合、現在のサイクル数や各ステージの状態を標準出力に出力します。
5. **レポート生成**:
   - `report(std::ostream& out)`メソッドでシミュレーションの統計情報を指定されたストリームに出力します。

## 例外・失敗条件
- メモリ読み込み関数（`load_memory`, `load_hex`）においてファイルが開けない場合、エラーが発生する可能性があります。
- 各ステージオブジェクトのメソッド呼び出しで内部的なエラーが発生する可能性があります。

## 重要な不変条件

- 各ステージオブジェクト（`Issue`, `OoOExecute`, `BranchPrediction`）はセッションのライフサイクルと同期して生成・破棄される。
