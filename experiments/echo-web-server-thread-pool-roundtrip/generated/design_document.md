# デザイン文書: スレッドプールモジュール

## 概要
この設計文書は、`thread_pool.h`と`thread_pool.cpp`に定義されているスレッドプールクラスの再実装に必要な情報を提供します。スレッドプールは指定された数のワーカースレッドを使用してタスクを並列に処理するためのコンポーネントです。

## 責務
- 指定された数のワーカースレッドを作成し、管理します。
- タスクキューにタスクをプッシュし、ワーカースレッドがタスクを実行できるようにします。
- スレッドプールを開始・停止する機能を提供します。

## 公開インターフェース
### コンストラクタ
```cpp
ThreadPool(std::optional<std::size_t> thread_count = std::nullopt, log::Logger::Ptr logger = log::RootLogger()) noexcept;
```
- `thread_count`: スレッドプールで使用するワーカースレッドの数。`std::nullopt`またはゼロの場合、ハードウェアがサポートする並列スレッド数を使用します。
- `logger`: ロガー。`nullptr`の場合、グローバルルートロガーを使用します。

### デストラクタ
```cpp
~ThreadPool() noexcept;
```

### コピー・ムーブコンストラクタと代入演算子
コピーとムーブは禁止されています。
```cpp
ThreadPool(const ThreadPool&) = delete;
ThreadPool(ThreadPool&&) = delete;
ThreadPool& operator=(const ThreadPool&) = delete;
ThreadPool& operator=(ThreadPool&&) = delete;
```

### メソッド
- `void Start() noexcept;`
  - スレッドプールを開始します。
- `void Push(Task task) noexcept;`
  - タスクキューにタスクをプッシュします。
- `void Close() noexcept;`
  - スレッドプールを閉じます。未処理のタスクは実行されません。

## 入力
- コンストラクタ: スレッド数とロガー（オプション）
- `Push`: 実行するためのタスク

## 出力
- なし（内部状態の変化）

## 状態
- `logger_`: ロガーへのポインタ。
- `mtx_`: タスクキューへのアクセスを同期するために使用されるミューテックス。
- `closed_`: スレッドプールが閉じているかどうかを示すフラグ。
- `thread_count_`: スレッドプールで使用するワーカースレッドの数。
- `cond_`: タスクキューにタスクが追加されたことを待つための条件変数。
- `tasks_`: 実行待ちのタスクを保持するリスト。
- `threads_`: ワーカースレッドを保持するリスト。

## 処理手順
1. **コンストラクタ**:
   - ロガーが指定されていない場合は、グローバルルートロガーを使用します。
   - スレッド数がゼロまたは未指定の場合、ハードウェアの並列スレッド数を使用します。

2. **デストラクタ**:
   - スレッドプールを閉じます。
   - すべてのワーカースレッドが終了するまで待ちます。

3. **Start()**:
   - `closed_`フラグをfalseに設定し、指定された数のワーカースレッドを作成します。各ワーカースレッドは`ExecProc()`メソッドを実行します。

4. **Push(Task task)**:
   - タスクキューにタスクを追加し、条件変数を使用して待機中のワーカースレッドを通知します。

5. **Close()**:
   - `closed_`フラグをtrueに設定し、すべてのワーカースレッドが終了するまで待ちます。

6. **ExecProc()**:
   - タスクキューからタスクを取り出し実行します。
   - 例外が発生した場合はロガーに記録します。
   - `closed_`フラグがtrueになったらワーカースレッドを終了します。

## 例外・失敗条件
- `Push(Task task)`メソッドはタスクキューへのアクセスを同期するためにミューテックスを使用します。ただし、タスクの実行中に例外が発生した場合はロガーに記録されますが再スローされません。
- スレッドプールが閉じている場合、`Push(Task task)`メソッドはアサートで失敗します。

## 依存関係
- `log::Logger`: ロギング機能を提供するクラス。
- `<condition_variable>`, `<functional>`, `<list>`, `<mutex>`, `<optional>`, `<thread>`: C++標準ライブラリのヘッダファイル。

## 重要な不変条件
- スレッドプールが閉じている場合、タスクキューに新しいタスクを追加することはできません。
- ワーカースレッドはタスクキューからタスクを取り出して実行し、タスクキューが空でないか、またはスレッドプールが閉じているまで待機します。
