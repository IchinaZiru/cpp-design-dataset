## クラス: Parser

### 責務
`Parser`クラスは、入力ストリームからデータを読み取り、それを指定されたメモリオブジェクトに書き込む責任を持っています。具体的には、16進数形式のデータを解析し、適切なアドレス位置に格納します。

### 公開インターフェース
- `static unsigned parse_hex(const std::string &hex)`
  - 機能: 16進数文字列を符号なし整数に変換する。
  - 引数: 16進数形式の文字列 (`std::string`)
  - 戻り値: 変換された符号なし整数 (`unsigned`)

- `static void parse(std::istream &in, Memory &mem)`
  - 機能: 入力ストリームからデータを読み取り、メモリオブジェクトに書き込む。
  - 引数:
    - `std::istream &in`: データの入力元となるストリーム
    - `Memory &mem`: データを格納するメモリオブジェクト

- `static void parse_hex(std::istream &in, Memory &mem)`
  - 機能: 入力ストリームから16進数データを読み取り、メモリオブジェクトに書き込む。
  - 引数:
    - `std::istream &in`: データの入力元となるストリーム
    - `Memory &mem`: データを格納するメモリオブジェクト

### 入力
- `parse_hex`:
  - 16進数形式の文字列 (`std::string`)
  
- `parse`:
  - 各行がデータまたはアドレス指定である入力ストリーム (`std::istream &in`)
  - データを格納するメモリオブジェクト (`Memory &mem`)

- `parse_hex`:
  - 16進数形式の単語（4バイト）を含む入力ストリーム (`std::istream &in`)
  - データを格納するメモリオブジェクト (`Memory &mem`)

### 出力
- `parse_hex`: 符号なし整数 (`unsigned`)
- `parse`, `parse_hex`: 直接出力はなく、データがメモリオブジェクトに書き込まれる。

### 状態
- 内部状態: なし（すべてのメンバ関数が`static`であり、インスタンス間で共有する状態がない）

### 処理手順

#### `parse_hex`
1. 入力ストリームから16進数文字列を読み取る。
2. 読み取った文字列を`strtol`関数を使用して符号なし整数に変換する。
3. 変換した値をメモリオブジェクトの現在のベースアドレス位置に書き込む。
4. ベースアドレスをインクリメントする。

#### `parse`
1. 入力ストリームが有効であることを確認し、無効な場合はエラーメッセージを出力する。
2. ベースアドレスを初期化する（0に設定）。
3. 入力ストリームから一行ずつ読み取り、以下の処理を行う:
   - 行の最初の文字が`@`である場合:
     - `@`以降の部分を16進数として解釈し、ベースアドレスを更新する。
   - それ以外の場合:
     - 行内の各16進数文字列を読み取り、それを符号なし整数に変換する。
     - 変換した値をメモリオブジェクトの現在のベースアドレス位置に書き込む。
     - ベースアドレスをインクリメントする。

### 例外・失敗条件
- 入力ストリームが無効な場合、エラーメッセージを出力し処理を継続する。
- `strtol`関数による変換に失敗した場合の具体的なハンドリングは行われていない。

### 依存関係
- `std::istream`: 入力ストリームの操作に使用される。
- `Memory`: データを格納するためのメモリオブジェクト。`Memory`クラスには、インデックス指定によるデータ書き込みと`write_word`メソッドが存在することが推測される。

### 重要な不変条件
- ベースアドレスは常に非負整数である。
- 入力ストリームから読み取られる16進数文字列は有効な形式であることが期待される。
