## 設計仕様書

### 全体概要

本設計仕様書は、`include/config.h` と `src/config/config.cpp` の再実装に必要な詳細を記述する。これらのファイルは、YAML形式の設定ファイルを読み込み、管理するための機能を提供する。特に、型変換のためのテンプレートメタプログラミングと、設定値の保持・アクセス方法に焦点を当てる。

### 3. 結果を決める式・具体値

*   `invalid_file_descriptor = -1`
*   `IsValidFileDescriptor(fd) = fd >= 0`
*   YAMLファイルの解析において、必須フィールドが存在しない場合に `std::invalid_argument` 例外をスローする。

### 4. 使用データ・更新データ

*   **`Var<T>`**: 型 `T` の設定値を保持し、`SetValue()` メソッドで更新される。
*   **`Config`**: 設定変数を `vars_` という `std::unordered_map` で管理する。
*   **`LoadYaml()`**: YAMLファイルから設定値を読み込み、対応する `Var<T>` オブジェクトの値を更新する。

### 5. 状態・副作用・不変条件

*   `Config` クラスは、設定変数の状態を保持する。
*   `SetValue()` メソッドは、設定値が変更された場合に登録されているリスナー関数を呼び出す。
*   YAMLファイルの読み込み中に例外が発生した場合、設定の状態は変更されない。
*   マルチスレッド環境において、`std::shared_mutex` を使用してデータへのアクセスを同期する。

### 9. メソッド仕様書

**`Config::Lookup<T>(const std::string_view name, const T& default_val)`**

*   **目的**: 指定された名前の設定変数を見つけるか、存在しない場合はデフォルト値で作成して返す。
*   **引数**:
    *   `name`: 設定変数の名前。
    *   `default_val`: 変数が存在しない場合に設定するデフォルト値。
*   **戻り値**: `Var<T>::Ptr` 型のスマートポインタ。見つかった、または作成された設定変数へのポインタ。
*   **副作用**: 新しい変数が作成される場合がある。

### 11. 状態遷移・副作用

*   `Config` オブジェクトは、設定変数の状態を保持する。
*   `LoadYaml()` メソッドは、YAMLファイルから読み込んだ値に基づいて設定変数の値を更新する。
*   `Var<T>::SetValue()` メソッドは、設定変数の値を変更し、登録されているリスナー関数を呼び出す。

### 12. データ変換・制約

*   `VarConverter` クラステンプレートを使用して、文字列と設定変数の型との間の変換を行う。
*   YAMLファイルから読み込まれた値は、`std::istringstream` を使用して適切な型に変換される。
*   変換に失敗した場合、`std::invalid_argument` 例外がスローされる。
