**3. Data Structures & Classes**

**3.1. Enums:**

*   **`AppenderType`**:  Represents the type of appender: `StdOut`, `File`.

**3.2. Classes:**

*   **`Event`**: Represents a single log event.
    *   Attributes: `level_`, `file_name_`, `line_num_`, `thread_id_`, `time_`, `msg_`.
    *   Methods:  `Create()` (static factory method), constructor (private, use `Create()`), getters for attributes, `MessageStream()` (returns an `ostringstream` to build the message).
*   **`Formatter`**: Responsible for formatting log events into strings.
    *   Attributes: `pattern_`, `fields_`.

*   **`FileAppender`**: Appends logs to a file. Inherits from `Appender`. Attributes: `file_name_`, `file_`.

*   **`Manager`**: Manages a collection of loggers. Provides a central point for accessing and configuring loggers. Attributes: `name_`, `loggers_`. Methods: Constructor, destructor, `FindLogger()`, `RemoveLogger()`, `ToYamlString()`.

**4. Key Functionality & Interactions**

1.  **Event Creation:** An `Event` is created using the static factory method `Event::Create()`, providing level, source location, thread ID and timestamp.
2.  **Logging:** A logger receives an event via its `Log()` method. If asynchronous logging is enabled, the event is added to a queue (`event_deque_`).
3.  **Asynchronous Logging:** A dedicated thread (`writer_thread_`) continuously processes events from the queue and writes them to all registered appenders using the `SyncLog` function.
4.  **Formatting:** Before writing to an appender, the event is formatted into a string by the logger's default formatter or the appender’s specific formatter. The formatter uses field objects to extract data from the event and format it according to the defined pattern.
5.  **Appending:** Each appender writes the formatted log message to its designated destination (e.g., standard output, file).
6. **Configuration**: A `Manager` is used to manage a set of `Logger` instances. The configuration system loads logger configurations and applies them to the managed loggers, setting their level, capacity, formatter, and appenders.
