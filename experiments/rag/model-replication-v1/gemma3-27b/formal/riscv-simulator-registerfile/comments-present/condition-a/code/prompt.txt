### 1. はじめに

本設計仕様書は、`RegisterFile`クラスの再実装に必要な情報を記述します。 このドキュメントは、提供されたヘッダーファイル (`src/Common/RegisterFile.hpp`) の内容に基づいています。  このクラスは、レジスタファイルを表現し、その状態を管理するためのものです。

### 2. クラス概要: RegisterFile

`RegisterFile`クラスは、32個のレジスタを持つレジスタファイルの実装を提供します。 レジスタの状態は、現在の値 (`prev`) と次の値 (`next`) の2つの配列で保持されます。 `tick()` メソッドによって、`next` 配列の内容が `prev` 配列にコピーされ、レジスタファイルの状態が更新されます。

**名前空間:**  (指定なし - グローバルスコープと想定)
**継承:** (指定なし - 単独クラスと想定)

### 3. データメンバ

*   **`REG_NUM`**: `static const int` 型の定数。レジスタの数を定義します。値は `32` です。
*   **`prev[REG_NUM]`**:  `Immediate` 型の配列。現在のレジスタ値を格納します。サイズは `REG_NUM` (32) です。
*   **`next[REG_NUM]`**: `Immediate` 型の配列。次のレジスタ値を格納します。サイズは `REG_NUM` (32) です。

**型定義:**  `Immediate` は、このドキュメントからは不明な型です。 再実装時には、提供されたソースコードから推測できないため、適切な型で置き換えてください。

### 4. メソッド

#### 4.1 コンストラクタ: `RegisterFile()`

*   **アクセス修飾子:** `public`
*   **引数:** なし
*   **戻り値:** なし
*   **機能:**  `prev` 配列と `next` 配列をゼロで初期化します。 `memset` 関数を使用しています。

#### 4.2 `tick()`

*   **アクセス修飾子:** `public`
*   **引数:** なし
*   **戻り値:** なし
*   **機能:**  `next` 配列の内容を `prev` 配列にコピーします。 `memcpy` 関数を使用しています。 これにより、レジスタファイルの状態が更新されます。

#### 4.3 `read(int id)`

*   **アクセス修飾子:** `public`
*   **引数:**
    *   `id`:  `int` 型。読み出すレジスタのIDです。
*   **戻り値:** `Immediate` 型。指定されたレジスタの現在の値を返します。
*   **機能:**
    *   `id` が 0 の場合、0 を返します。
    *   それ以外の場合、`prev[id]` の値を返します。

#### 4.4 `write(int id, Immediate val)`

*   **アクセス修飾子:** `public`
*   **引数:**
    *   `id`:  `int` 型。書き込むレジスタのIDです。
    *   `val`:  `Immediate` 型。書き込む値です。
*   **戻り値:** なし
*   **機能:** `next[id]` に `val` の値を書き込みます。

#### 4.5 `debug()`

*   **アクセス修飾子:** `public`
*   **引数:** なし
*   **戻り値:** なし
*   **機能:** レジスタファイルの内容を標準出力にデバッグ情報として出力します。
    *   レジスタは4x8のグリッドで表示されます。
    *   各レジスタには、`#0` から `#31` までの番号が付けられます。
    *   レジスタ名 (ra, sp, gp, tp, t0-t6, s0-s11, a0-a7) が対応するレジスタIDとともに表示されます。
    *   `debug_immediate()` 関数を使用して、各レジスタの `next` の値をデバッグ形式で出力します (引数: レジスタ値, 11)。

**依存関係:**  `debug_immediate()` はこのドキュメントからは不明な関数です。 再実装時には、提供されたソースコードから推測できないため、適切な代替手段を検討してください。 `std::cout`, `std::setw`, `sprintf` を使用します。
