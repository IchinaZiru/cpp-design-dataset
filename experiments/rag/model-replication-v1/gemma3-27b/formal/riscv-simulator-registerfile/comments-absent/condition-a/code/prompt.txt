## 設計仕様書: RegisterFile クラス

**ドキュメントバージョン:** 1.0
**日付:** 2023-10-27

### 1. はじめに

このドキュメントは、`RegisterFile`クラスの設計仕様を記述します。 このクラスは、レジスタファイルの実装を提供し、レジスタ値の読み書きと更新を行います。  この仕様は、提供されたC++コードに基づいており、推測に基づいた情報は含まれません。

### 2. 全体概要

`RegisterFile` クラスは、固定サイズのレジスタセットを管理します。 レジスタファイルは、現在のレジスタ値 (`next`) と前のレジスタ値 (`prev`) の両方を保持し、各クロックサイクルで値を更新する機能を提供します。  デバッグ用の出力関数も含まれます。

### 3. 詳細設計

#### 3.1 クラス定義

```c++
class RegisterFile {
    static const int REG_NUM = 32;
public:
    Immediate prev[REG_NUM];
    Immediate next[REG_NUM];

    RegisterFile();
    void tick();
    Immediate read(int id);
    void write(int id, Immediate val);
    void debug();
};
```

#### 3.2 メンバ変数

*   `prev[REG_NUM]`:  `Immediate`型の配列。前のクロックサイクルのレジスタ値を格納します。 サイズは `REG_NUM` (32) です。
*   `next[REG_NUM]`:  `Immediate`型の配列。現在のクロックサイクルのレジスタ値を格納します。 サイズは `REG_NUM` (32) です。

#### 3.3 コンストラクタ

*   `RegisterFile()`:  コンストラクタです。
    *   `prev` 配列をゼロで初期化します (`memset(prev, 0, sizeof(prev));`)。
    *   `next` 配列をゼロで初期化します (`memset(next, 0, sizeof(next));`)。

#### 3.4 メソッド

*   `void tick()`:  レジスタファイルを更新します。
    *   `prev` 配列の内容を `next` 配列にコピーします (`memcpy(prev, next, sizeof(prev));`)。 これにより、現在のレジスタ値が前のサイクル用に保存されます。

*   `Immediate read(int id)`:  指定されたIDのレジスタ値を読み取ります。
    *   引数 `id`: 読み取るレジスタのID (0から31)。
    *   `id` が 0 の場合、0 を返します。
    *   それ以外の場合、`prev[id]` の値を返します。

*   `void write(int id, Immediate val)`:  指定されたIDのレジスタに値を書き込みます。
    *   引数 `id`: 書き込むレジスタのID (0から31)。
    *   引数 `val`: レジスタに書き込む値 (`Immediate`型)。
    *   `next[id]` に `val` を書き込みます。

*   `void debug()`:  レジスタファイルの内容をデバッグ出力します。
    *   固定されたレジスタ名配列 `rf_name` を使用して、各レジスタのラベルを表示します。
        ```c++
        static std::vector<std::string> rf_name = {"0", "ra", "sp", "gp", "tp", "t0", "t1", "t2",
                                                   "s0", "s1", "a0", "a1", "a2", "a3", "a4", "a5",
                                                   "a6", "a7", "s2", "s3", "s4", "s5", "s6", "s7",
                                                   "s8", "s9", "s10", "s11", "t3", "t4", "t5", "t6"};
        ```
    *   レジスタを4x8のグリッドで表示します。
    *   各レジスタのIDと名前を表示します。
    *   `debug_immediate()` 関数を使用して、各レジスタの `next` の値をデバッグ出力します (引数 11 を使用)。

#### 3.5 型定義

*   `Immediate`:  この型は提供されたコードでは定義されていませんが、レジスタに格納される値の型を表すものと想定されます。 再実装時には適切な型を使用してください。

### 4. 制約事項

*   `REG_NUM` は常に32である必要があります。
*   `read()` および `write()` メソッドへの `id` 引数は、0から31 (両端を含む) の範囲内である必要があります。  範囲外のアクセスに対するエラー処理は定義されていません。

### 5. 今後の拡張

*   レジスタファイルサイズの動的な変更機能を追加する。
*   不正なIDアクセスに対するエラーチェックを追加する。
*   `debug_immediate()` 関数の詳細を明確にする (この仕様では、その実装は不明です)。
