## 設計仕様書: Parser クラス

**ドキュメントバージョン:** 1.0
**日付:** 2023-10-27
**対象読者:** LLM開発者 (このソースコードにアクセスできない)

### 1. はじめに

本設計仕様書は、`Parser`クラスの再実装に必要な情報を記述します。 このドキュメントは、提供されたC++ヘッダファイル (`src/Common/Parser.hpp`) の内容に基づいています。  このクラスは、入力ストリームからデータを解析し、`Memory`オブジェクトに格納するための静的メソッドを提供します。

### 2. 全体概要

`Parser` クラスは、文字列またはストリームから16進数を解析し、それをメモリに書き込むためのユーティリティ関数を提供するように設計されています。  このクラスには、異なる解析方法を扱う3つの静的メソッドが含まれています。

### 3. 詳細設計

#### 3.1 クラス定義

```c++
class Parser {
public:
    // ... (メソッドの詳細が以下に記述されます)
};
```

#### 3.2 静的メソッド `parse_hex`

*   **名前:** `parse_hex`
*   **戻り値の型:** `unsigned`
*   **引数:**
    *   `const std::string &hex`: 解析する16進数の文字列。
*   **機能:**  入力された16進数の文字列を符号なし整数に変換します。
*   **実装詳細:** `strtol`関数を使用して、16進数文字列を`unsigned`型に変換します。
*   **エラー処理:** 入力文字列が有効な16進数でない場合、`strtol`の動作に従います (通常は0を返します)。

```c++
static unsigned parse_hex(const std::string &hex);
```

#### 3.3 静的メソッド `parse`

*   **名前:** `parse`
*   **戻り値の型:** `void`
*   **引数:**
    *   `std::istream &in`: 入力ストリーム。
    *   `Memory &mem`:  解析されたデータを格納するメモリオブジェクト。
*   **機能:** 入力ストリームから1行ずつ読み込み、'@'で始まる行をベースアドレスとして解釈し、それ以外の行をデータとして解析してメモリに書き込みます。
*   **実装詳細:**
    1.  入力ストリーム `in` が有効かどうかを確認します。無効な場合は標準エラー出力にメッセージを出力します。
    2.  `base_addr` を 0 で初期化します。
    3.  入力ストリームから行を読み込み、以下の処理を繰り返します:
        *   行の最初の文字が '@' の場合:
            *   '@' 以降の文字列を16進数として解釈し、`base_addr` に格納します。 `strtol`を使用します。
        *   それ以外の場合:
            *   行をstringstreamに渡します。
            *   stringstreamから16進数の文字列を読み込み、以下の処理を繰り返します:
                *   空の文字列の場合はループを終了します。
                *   `parse_hex` を使用して16進数を `char` 型に変換します。
                *   `mem[base_addr++] = data;` でメモリに書き込みます。
*   **エラー処理:** 入力ストリームが無効な場合、標準エラー出力にメッセージを出力します。

```c++
static void parse(std::istream &in, Memory &mem);
```

#### 3.4 静的メソッド `parse_hex` (オーバーロード)

*   **名前:** `parse_hex`
*   **戻り値の型:** `void`
*   **引数:**
    *   `std::istream &in`: 入力ストリーム。
    *   `Memory &mem`: 解析されたデータを格納するメモリオブジェクト。
*   **機能:**  入力ストリームから16進数の文字列を読み込み、それを4バイトのワードとしてメモリに書き込みます。
*   **実装詳細:**
    1. 入力ストリーム `in` が有効かどうかを確認します。無効な場合は標準エラー出力にメッセージを出力します。
    2.  `base_addr` を 0 で初期化します。
    3.  入力ストリームから16進数の文字列を読み込み、以下の処理を繰り返します:
        *   `parse_hex` を使用して16進数を `unsigned` 型に変換します。
        *   `mem.write_word(base_addr, parse_hex(hex));` でメモリに書き込みます。
        *   `base_addr += 4;` でベースアドレスをインクリメントします。
*   **エラー処理:** 入力ストリームが無効な場合、標準エラー出力にメッセージを出力します。

```c++
static void parse_hex(std::istream &in, Memory &mem);
```

### 4. 依存関係

*   `std::string`: 文字列操作に使用されます。
*   `std::istream`: 入力ストリームを扱うために使用されます。
*   `Memory`:  解析されたデータを格納するためのカスタムクラスです。 このクラスの具体的な実装は提供されていませんが、`write_word`メソッドを持つことがわかります。
*   `strtol`: 文字列を整数に変換するために使用されます。
*   `std::stringstream`: 文字列をストリームとして扱うために使用されます。

### 5. 注意事項

*   `Memory`クラスのインターフェースは不明であるため、提供された情報に基づいて実装する必要があります。 特に `write_word` メソッドの動作に注意してください。
*   エラー処理は標準エラー出力へのメッセージ出力のみです。 必要に応じて、より堅牢なエラー処理メカニズムを実装できます。
*   この仕様書は、提供されたコードスニペットに基づいています。 コード全体が利用できないため、推測による実装は避けてください。
