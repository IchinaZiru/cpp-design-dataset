## 設計仕様書: INIWriter クラス

**ドキュメントバージョン:** 1.0
**日付:** 2023-10-27
**対象読者:** LLM開発者 (このソースコードにアクセスできない)

### 1. はじめに

本設計仕様書は、`INIWriter` クラスの再実装に必要な情報を記述します。 このクラスは、`INIReader` オブジェクトから読み取ったデータを指定されたファイルパスにINI形式で書き込む機能を提供します。

### 2. 全体概要

`INIWriter` クラスは、INIファイルを生成するための静的メソッド `write()` を提供するシンプルなクラスです。  このクラスにはコンストラクタしかありません（デフォルトコンストラクタ）。

### 3. クラス定義: INIWriter

**名前空間:** (指定なし - グローバルスコープ)
**クラス名:** `INIWriter`

#### 3.1 コンストラクタ

*   **アクセス修飾子:** public
*   **名前:** `INIWriter()`
*   **引数:** なし
*   **戻り値:** なし
*   **説明:** デフォルトコンストラクタ。  このクラスのインスタンスを作成します。
*   **実装詳細:** デフォルト実装で問題ありません。

#### 3.2 静的メソッド: write()

*   **アクセス修飾子:** public, inline, static
*   **名前:** `write()`
*   **引数:**
    *   `const std::string& filepath`: 書き込み先のファイルパスを表す文字列。
    *   `const INIReader& reader`:  INIデータを読み込んだ `INIReader` オブジェクトへの参照。
    *   `const bool overwrite = false`: ファイルが存在する場合に上書きするかどうかを示すブール値。デフォルトは `false` です。
*   **戻り値:** なし
*   **例外:**
    *   `std::runtime_error`:  以下のいずれかの条件が満たされた場合にスローされます。
        *   `overwrite` が `false` で、指定されたファイルパスにファイルが既に存在する場合。エラーメッセージは "file: [filepath] already exists." となります。
        *   出力ファイルをオープンできない場合。エラーメッセージは "cannot open output file: [filepath]" となります。
*   **説明:**  `INIReader` オブジェクトから読み取ったINIデータを、指定されたファイルパスに書き込みます。 `overwrite` パラメータが `false` の場合、ファイルが存在すると例外をスローします。
*   **実装詳細:**

    1.  `filepath` に対応するファイルが既に存在し、かつ `overwrite` が `false` である場合、`std::runtime_error` をスローします。
    2.  指定された `filepath` で出力ファイルストリーム (`std::ofstream`) をオープンします。
    3.  ファイルストリームのオープンに失敗した場合、`std::runtime_error` をスローします。
    4.  `INIReader` オブジェクトからセクションを反復処理します。
        *   各セクションに対して、角括弧で囲まれたセクション名をファイルに書き込みます (例: `[section_name]\n`)。
        *   現在のセクションのキーを反復処理します。
            *   各キーに対して、`key=value\n` の形式でキーと値をファイルに書き込みます。  値は `INIReader::Get(section, key)` から取得されます。

### 4. 依存関係

*   `<string>`: 文字列操作のために必要です。
*   `<fstream>`: ファイル入出力のために必要です。
*   `INIReader`: INIデータの読み取りに使用されるクラス。このクラスの定義は本仕様書に含まれていませんが、`write()` メソッドの引数として使用されます。

### 5. 注意事項

*   エラーメッセージは正確に上記のとおりに実装してください。
*   ファイルパスは絶対パスまたは相対パスである可能性があります。
*   `INIReader` クラスのインターフェース（特に `Sections()`, `Keys(section)`, `Get(section, key)` メソッド）を理解しておく必要があります。
*   このクラスは、INIファイルの書き込みのみを担当し、読み取り機能はありません。
