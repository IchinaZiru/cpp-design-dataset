**目的:** バッファに指定されたサイズのデータを追加する。

**戻り値:** なし
**副作用:** `write_pos_`が更新される。バッファのサイズが変更される可能性がある。
**前提条件:** `data`は有効なメモリ領域を指していること。
**事後条件:** データがバッファに追加され、`write_pos_`が更新されていること。
