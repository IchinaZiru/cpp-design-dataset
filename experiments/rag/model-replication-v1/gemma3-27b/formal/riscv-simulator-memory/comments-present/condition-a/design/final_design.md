## 設計仕様書: Memory クラス

**ドキュメントバージョン:** 1.0
**日付:** 2023-10-27

### 1. はじめに

このドキュメントは、`Memory`クラスの設計仕様を記述します。 このクラスは、固定サイズのメモリ領域へのアクセスと操作を提供します。  この仕様は、提供されたC++コードに基づいており、推測は行いません。

### 2. 全体概要

`Memory` クラスは、プログラムが使用するメモリ空間を表します。 これは、バイト配列 (`mem`) を保持し、その配列に対する読み書きアクセスを提供します。 アドレスの範囲チェックも提供されます。

### 3. 詳細設計

#### 3.1 クラス名

`Memory`

#### 3.2 ヘッダーファイル

`src/Common/Memory.hpp`

#### 3.3 データメンバ

*   `unsigned char mem[MEMORY_SIZE]`: メモリ領域を格納するバイト配列。 `MEMORY_SIZE` は定義済みの定数です (値は提供されていません)。
*   `unsigned char placeholder`: アドレスチェックに失敗した場合に返されるプレースホルダー値。

#### 3.4 コンストラクタ

*   `Memory()`:  コンストラクタは、メモリ領域 (`mem`) をゼロで初期化します。 `memset(mem, 0, sizeof(mem))`を使用します。

#### 3.5 メソッド

*   **`bool check_addr(unsigned int addr)`**:
    *   **機能:** 指定されたアドレスが有効な範囲内にあるかどうかをチェックします。
    *   **引数:**
        *   `addr`: チェックするアドレス (符号なし整数)。
    *   **戻り値:** アドレスが `0 <= addr < MEMORY_SIZE` の範囲内であれば `true`、それ以外の場合は `false` を返します。
    *   **注記:** TODOコメントに例外処理の検討事項が含まれていますが、実装は提供されていません。

*   **`Immediate read_word(unsigned int addr)`**:
    *   **機能:** 指定されたアドレスからワード (4バイト) を読み取ります。
    *   **引数:**
        *   `addr`: 読み取るアドレス (符号なし整数)。
    *   **戻り値:** アドレスが有効な場合、指定されたアドレスにある `Immediate` 型の値を返します。 無効なアドレスの場合は `0` を返します。
    *   **型:**  `Immediate` は定義済みの型です（具体的な定義は提供されていません）。

*   **`void write_word(unsigned int addr, Immediate imm)`**:
    *   **機能:** 指定されたアドレスにワード (4バイト) を書き込みます。
    *   **引数:**
        *   `addr`: 書き込むアドレス (符号なし整数)。
        *   `imm`: 書き込む `Immediate` 型の値。
    *   **戻り値:** なし (`void`)。
    *   **注記:** アドレスチェックはメソッド内で実行されます。

*   **`unsigned short read_ushort(unsigned int addr)`**:
    *   **機能:** 指定されたアドレスから符号なしショート (2バイト) を読み取ります。
    *   **引数:**
        *   `addr`: 読み取るアドレス (符号なし整数)。
    *   **戻り値:** アドレスが有効な場合、指定されたアドレスにある `unsigned short` 型の値を返します。 無効なアドレスの場合は `0` を返します。

*   **`void write_ushort(unsigned int addr, unsigned short imm)`**:
    *   **機能:** 指定されたアドレスに符号なしショート (2バイト) を書き込みます。
    *   **引数:**
        *   `addr`: 書き込むアドレス (符号なし整数)。
        *   `imm`: 書き込む `unsigned short` 型の値。
    *   **戻り値:** なし (`void`)。
    *   **注記:** アドレスチェックはメソッド内で実行されます。

*   **`unsigned char &operator[](unsigned int addr)`**:
    *   **機能:**  配列アクセス演算子をオーバーロードして、指定されたアドレスのバイトへのアクセスを提供します。
    *   **引数:**
        *   `addr`: アクセスするアドレス (符号なし整数)。
    *   **戻り値:** アドレスが有効な場合は、メモリ領域 (`mem`) の対応するバイトへの参照を返します。 無効なアドレスの場合は、`placeholder` への参照を返します。

*   **`void debug()`**:
    *   **機能:** メモリの内容の一部を標準出力にデバッグ情報として出力します。
    *   **引数:** なし
    *   **戻り値:** なし (`void`)
    *   **注記:**  アドレス範囲 `0x20000 - 0x10` から `0x20000` までのバイトを16進数で出力します。

### 4. 制約事項

*   `MEMORY_SIZE` 定数の値は、この仕様では定義されていません。
*   `Immediate` 型の具体的な定義は提供されていません。
*   アドレスチェックに失敗した場合の例外処理は実装されていませんが、TODOコメントで将来的な検討が示唆されています。
