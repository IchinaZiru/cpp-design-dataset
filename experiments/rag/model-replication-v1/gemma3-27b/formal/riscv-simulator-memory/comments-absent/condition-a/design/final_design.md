## 設計仕様書: Memory クラス

**ドキュメントバージョン:** 1.0
**日付:** 2023-10-27

### 1. はじめに

このドキュメントは、`Memory`クラスの設計仕様を記述します。 この仕様は、提供されたC++ソースコードに基づいており、別のLLMがこのクラスを再実装するために使用されます。  入力から推測できる情報のみを含み、不明な点は明示的に記載しません。

### 2. 全体概要

`Memory` クラスは、固定サイズのメモリ領域を表します。 このクラスは、メモリへの読み書き操作とアドレスの有効性チェックを提供します。 デバッグ目的でメモリの内容を出力する機能も含まれます。

### 3. 詳細設計

#### 3.1 クラス名

*   `Memory`

#### 3.2 ヘッダーファイル

*   `src/Common/Memory.hpp` (このパスは重要です)

#### 3.3 データメンバ

*   `unsigned char mem[MEMORY_SIZE]` : メモリ領域を格納する unsigned char 型の配列。 `MEMORY_SIZE` は定義済みの定数であると想定します。（値はソースコードからは不明）
*   `unsigned char placeholder`: アドレスチェックに失敗した場合に返すプレースホルダーの値。

#### 3.4 コンストラクタ

*   `Memory()`:  コンストラクタは、メモリ領域 `mem` をゼロで初期化します。 `memset(mem, 0, sizeof(mem))`を使用します。

#### 3.5 メソッド

*   **`bool check_addr(unsigned int addr)`**:
    *   **機能:** 指定されたアドレスが有効かどうかをチェックします。
    *   **引数:**
        *   `addr`: チェックするアドレス (unsigned int)。
    *   **戻り値:** アドレスが有効な場合は `true`、そうでない場合は `false`。 有効なアドレスの範囲は 0 <= addr < MEMORY_SIZE です。

*   **`Immediate read_word(unsigned int addr)`**:
    *   **機能:** 指定されたアドレスから `Immediate` 型の値（ワード）を読み取ります。
    *   **引数:**
        *   `addr`: 読み取るアドレス (unsigned int)。
    *   **戻り値:** アドレスが有効な場合は、指定されたアドレスにある `Immediate` 値。 無効なアドレスの場合は 0。
    *   **実装詳細:**  メモリを `Immediate*` 型のポインタとして解釈して値を読み取ります。

*   **`void write_word(unsigned int addr, Immediate imm)`**:
    *   **機能:** 指定されたアドレスに `Immediate` 型の値（ワード）を書き込みます。
    *   **引数:**
        *   `addr`: 書き込むアドレス (unsigned int)。
        *   `imm`: 書き込む値 (Immediate)。
    *   **戻り値:** なし。
    *   **実装詳細:** アドレスチェックを行い、有効な場合はメモリを `Immediate*` 型のポインタとして解釈して値を書き込みます。

*   **`unsigned short read_ushort(unsigned int addr)`**:
    *   **機能:** 指定されたアドレスから `unsigned short` 型の値（ハーフワード）を読み取ります。
    *   **引数:**
        *   `addr`: 読み取るアドレス (unsigned int)。
    *   **戻り値:** アドレスが有効な場合は、指定されたアドレスにある `unsigned short` 値。 無効なアドレスの場合は 0。
    *   **実装詳細:** メモリを `short*` 型のポインタとして解釈して値を読み取ります。

*   **`void write_ushort(unsigned int addr, unsigned short imm)`**:
    *   **機能:** 指定されたアドレスに `unsigned short` 型の値（ハーフワード）を書き込みます。
    *   **引数:**
        *   `addr`: 書き込むアドレス (unsigned int)。
        *   `imm`: 書き込む値 (unsigned short)。
    *   **戻り値:** なし。
    *   **実装詳細:** アドレスチェックを行い、有効な場合はメモリを `short*` 型のポインタとして解釈して値を書き込みます。

*   **`unsigned char &operator[](unsigned int addr)`**:
    *   **機能:** 指定されたアドレスにある `unsigned char` への参照を返します。  配列アクセス演算子オーバーロードです。
    *   **引数:**
        *   `addr`: アクセスするアドレス (unsigned int)。
    *   **戻り値:** アドレスが有効な場合は、指定されたアドレスにある `unsigned char` 型の参照。 無効なアドレスの場合は、`placeholder` への参照。

*   **`void debug()`**:
    *   **機能:** メモリの内容を標準出力に出力します。
    *   **引数:** なし。
    *   **戻り値:** なし。
    *   **実装詳細:** アドレス範囲 `0x20000 - 0x10` から `0x20000` までを16進数で出力します。

#### 3.6 型定義

*   `Immediate`:  この型はソースコードから不明です。 再実装するLLMはこの型を定義する必要があります。

#### 3.7 定義済みの定数

*   `MEMORY_SIZE`: この定数はソースコードから不明です。再実装するLLMはこの定数を定義する必要があります。
### 4. 注意事項

*   この仕様は、提供されたC++コードに基づいており、他の情報源からの推測を含みません。
*   `Immediate` 型と `MEMORY_SIZE` 定数の具体的な定義は、このドキュメントからは不明です。 再実装するLLMは、これらの定義を別途確認する必要があります。
*   アドレスチェックの失敗時に返されるプレースホルダーの値は `placeholder` データメンバで定義されています。
