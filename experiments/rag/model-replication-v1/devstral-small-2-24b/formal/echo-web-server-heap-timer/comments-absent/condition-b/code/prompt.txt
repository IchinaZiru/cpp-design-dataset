## 5. メソッド仕様書

### Push

```cpp
void Push(const Key& key, Clock::duration expiration,
          TimeOutCallback callback) noexcept;
```

- **目的**: 新しいタイムアウトイベントを追加する
- **引数**:
  - `key`: イベントの一意識別子
  - `expiration`: 期限までの期間（現在時刻から）
  - `callback`: 期限切れ時に実行されるコールバック関数
- **戻り値**: なし
- **副作用**:
  - 新しいノードをヒープに追加する
  - キーとインデックスのマッピングを更新する
  - ヒープ構造を維持するためにShiftUpを行う
- **例外**: 投げない

### Tick

```cpp
void Tick() noexcept;
```

- **目的**: 期限切れのイベントを実行する
- **引数**: なし
- **戻り値**: なし
- **副作用**:
  - 期限切れのイベントのコールバックを実行する
  - 実行されたイベントをヒープから削除する
  - コールバック実行中に例外が発生した場合はログに記録する
- **例外**: 投げない

### Adjust

```cpp
void Adjust(const Key& key, Clock::time_point expiration);
```

- **目的**: 既存のタイムアウトイベントの期限を更新する
- **引数**:
  - `key`: 更新対象のイベントのキー
  - `expiration`: 新しい期限時刻
- **戻り値**: なし
- **副作用**:
  - 指定したキーのノードの期限を更新する
  - 期限が短くなった場合はShiftUpを行う
  - 期限が長くなった場合はShiftDownを行う
- **例外**: `std::out_of_range`（キーが存在しない場合）

| 状態 | 遷移条件 | 副作用 |

| 更新前 | 既存キーで `Adjust()` が呼ばれた時 | ノードの期限を更新し、必要に応じてヒープ構造を修正する |
| 実行前 | `Tick()` が呼ばれた時 | 期限切れノードのコールバックを実行し、削除する |

## 8. データ変換・制約

### ヒープ操作

- **ShiftUp**: ノードを親と比較し、必要に応じて上方向へ移動させる
  - 比較基準: `expiration` の小さい方が優先（最小ヒープ）
  - 終了条件: 親よりも大きい場合またはルートに到達した場合

- **ShiftDown**: ノードを子と比較し、必要に応じて下方向へ移動させる
  - 比較基準: `expiration` の小さい方が優先（最小ヒープ）
  - 終了条件: 両方の子よりも小さい場合または葉に到達した場合

### 制約

- キーは一意である必要がある
- `Clock::duration` は正の値であること
- コールバック関数は例外を投げる可能性があるため、呼び出し側で適切な例外処理を行う必要がある

## 10. 追加詳細設計情報

### ヒープ構造の具体的な動作

1. **挿入**:
   - 新しいノードをデックの末尾に追加する
   - `ShiftUp` を呼び出してヒープ構造を修正する
   - `ShiftUp` は親と比較し、必要に応じて上方向へ移動させる

2. **削除**:
   - 削除対象のノードを末尾のノードと交換する
   - 末尾のノードを削除する
   - `ShiftDown` を呼び出してヒープ構造を修正する
   - `ShiftDown` は子と比較し、必要に応じて下方向へ移動させる

3. **更新**:
   - ノードの期限を更新する
   - 期限が短くなった場合は `ShiftUp` を呼び出す
   - 期限が長くなった場合は `ShiftDown` を呼び出す

### エラー処理

- コールバック実行中に例外が発生した場合、ログに記録される
- キーが存在しない場合、`Adjust` は `std::out_of_range` を投げる
- `Pop` は空のヒープから呼び出された場合に `assert` する（デバッグ時のみ）

### パフォーマンス特性

- `Push`: O(log n) - ヒープへの挿入とShiftUpによる修正
- `Adjust`: O(log n) - ノードの更新と必要な方向への移動
- `Tick`: O(k log n) - k個の期限切れイベントを処理する場合
- `Remove`: O(log n) - ヒープからの削除とShiftDownによる修正

この設計仕様書は、元コードから確認できる事実のみを記述しており、再実装に必要な情報が網羅されています。
