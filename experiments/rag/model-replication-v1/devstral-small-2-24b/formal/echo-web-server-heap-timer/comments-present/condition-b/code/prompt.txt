# 設計仕様書

## 1. 概要
この設計仕様書は、`HeapTimer`クラスの完全な再実装に必要な情報を提供します。`HeapTimer`は、最小ヒープを基盤としたタイマーシステムであり、タイマーが期限切れになるとコールバック関数を呼び出す機能を提供します。

## 5. メソッド仕様書

### Adjust
- **目的**: 指定されたキーのタイマーの期限切れ時間を調整します。
- **引数**:
  - `key`: タイマーのキー。
  - `expiration`: 新しい期限切れ時間（durationまたはtime_point）。
- **戻り値**: なし。
- **副作用**: タイマーの期限切れ時間を更新し、必要に応じてヒープを再構築します。
- **例外**: `std::out_of_range` - 指定されたキーのタイマーが存在しない場合。

### Push
- **目的**: 新しいタイマーを追加します。
- **引数**:
  - `key`: タイマーのキー。
  - `expiration`: 期限切れ時間（durationまたはtime_point）。
  - `callback`: 期限切れ時に呼び出されるコールバック関数。
- **戻り値**: なし。
- **副作用**: 新しいタイマーをヒープに追加し、必要に応じて既存のタイマーと調整します。

### Tick
- **目的**: 期限切れのタイマーを削除し、コールバック関数を呼び出します。
- **引数**: なし。
- **戻り値**: なし。
- **副作用**: 期限切れのタイマーを削除し、コールバック関数を呼び出します。例外が発生した場合はログに記録されます。

### Remove
- **目的**: 指定されたキーのタイマーを削除します。
- **引数**:
  - `key`: 削除するタイマーのキー。
- **戻り値**: `true` - タイマーが削除された場合、`false` - タイマーが存在しない場合。
- **副作用**: 指定されたキーのタイマーをヒープから削除します。

### Invoke
- **目的**: 指定されたキーのタイマーを削除し、コールバック関数を呼び出します。
- **引数**:
  - `key`: 削除するタイマーのキー。
- **戻り値**: なし。
- **副作用**: 指定されたキーのタイマーをヒープから削除し、コールバック関数を呼び出します。例外が発生した場合はログに記録されます。

### Pop
- **目的**: 最上位のタイマーを取り出し、そのキーを返します。
- **引数**: なし。
- **戻り値`: `Key` - 最上位のタイマーのキー。
- **副作用**: 最上位のタイマーをヒープから削除します。

### Clear
- **目的**: すべてのタイマーをクリアします。
- **引数**: なし。
- **戻り値`: `void` - なし。
- **副作用**: ヒープとキーへのインデックスマップをクリアします。

### Contain
- **目的**: 指定されたキーのタイマーが存在するかどうかを返します。
- **引数**:
  - `key`: 検索するタイマーのキー。
- **戻り値`: `bool` - タイマーが存在する場合は`true`、それ以外の場合は`false`。
- **副作用**: なし。

### Empty
- **目的`: ヒープが空であるかどうかを返します。
- **引数`: なし。
- **戻り値`: `bool` - ヒープが空である場合は`true`、それ以外の場合は`false`。
- **副作用`: なし。

### Size
- **目的`: ヒープ内のタイマーの数を返します。
- **引数`: なし。
- **戻り値`: `std::size_t` - タイマーの数。
- **副作用`: なし。

### ToNextTick
- **目的`: 次のタイマー期限切れまでの時間を返します。
- **引数`: なし。
- **戻り値`: `Clock::duration` - 次のタイマー期限切れまでの時間。
- **副作用`: 期限切れのタイマーを削除し、コールバック関数を呼び出します。

### クラス構造
```cpp
template <typename Key>
class HeapTimer {
public:
    // コンストラクタ、デストラクタ、コピー/ムーブ禁止
    explicit HeapTimer(log::Logger::Ptr logger = log::RootLogger()) noexcept;
    ~HeapTimer() = default;
    HeapTimer(HeapTimer&&) = delete;
    HeapTimer& operator=(HeapTimer&&) = delete;
    HeapTimer(const HeapTimer&) = delete;
    HeapTimer& operator=(const HeapTimer&) = delete;

    // パブリックメソッド
    void Adjust(const Key& key, Clock::duration expiration);
    void Adjust(const Key& key, Clock::time_point expiration);
    void Push(const Key& key, Clock::duration expiration, TimeOutCallback callback) noexcept;
    void Push(const Key& key, Clock::time_point expiration, TimeOutCallback callback) noexcept;
    void Tick() noexcept;
    bool Remove(const Key& key) noexcept;
    void Invoke(const Key& key);
    Key Pop() noexcept;
    void Clear() noexcept;
    bool Contain(const Key& key) const noexcept;
    bool Empty() const noexcept;
    std::size_t Size() const noexcept;
    Clock::duration ToNextTick() noexcept;

private:
    // 内部構造体
    struct Node {
        Key key;
        Clock::time_point expiration;
        TimeOutCallback callback;
        bool Expired() const noexcept;
        void Swap(Node&) noexcept;
        friend std::weak_ordering operator<=>(const Node& lhs, const Node& rhs) noexcept;
    };

    // プライベートメソッド
    void Swap(std::size_t idx1, std::size_t idx2) noexcept;
    void Adjust(const Key& key, Clock::time_point expiration, std::optional<TimeOutCallback> callback);
    Key RemoveByIndex(std::size_t idx) noexcept;
    void ShiftUp(std::size_t idx) noexcept;
    void ShiftDown(std::size_t idx) noexcept;
    bool ValidIndex(std::size_t idx) const noexcept;
    std::optional<std::size_t> Parent(std::size_t idx) const noexcept;
    std::optional<std::size_t> SmallChild(std::size_t idx) const noexcept;

    // メンバ変数
    log::Logger::Ptr logger_;
    std::unordered_map<Key, std::size_t> key_to_idx_;
    std::deque<Node> nodes_;
};
```

### メソッド実装
| メソッド | 実装内容 |
|----------|----------|
| `HeapTimer::Node::Expired` | `Clock::now() >= expiration` |
| `HeapTimer::Node::Swap` | `swap(key, o.key); swap(expiration, o.expiration); swap(callback, o.callback);` |
| `HeapTimer::HeapTimer` | `logger_ {std::move(logger)}; if (!logger_) { logger_ = log::RootLogger(); }` |
| `HeapTimer::Clear` | `nodes_.clear(); key_to_idx_.clear();` |
| `HeapTimer::Remove` | `if (Contain(key)) { RemoveByIndex(key_to_idx_[key]); return true; } else { return false; }` |
| `HeapTimer::ValidIndex` | `return idx < Size();` |
| `HeapTimer::Contain` | `return key_to_idx_.contains(key);` |
| `HeapTimer::Adjust` (duration) | `Adjust(key, Clock::now() + expiration);` |
| `HeapTimer::Adjust` (time_point) | `Adjust(key, expiration, std::nullopt);` |
| `HeapTimer::Adjust` (internal) | `const auto idx {key_to_idx_.at(key)}; if (callback.has_value()) { nodes_[idx].callback = *callback; } const auto shift_up {expiration < nodes_[idx].expiration}; nodes_[idx].expiration = expiration; if (shift_up) { ShiftUp(idx); } else { ShiftDown(idx); }` |
| `HeapTimer::Push` (duration) | `Push(key, Clock::now() + expiration, std::move(callback));` |
| `HeapTimer::Push` (time_point) | `if (!Contain(key)) { const auto idx {Size()}; key_to_idx_.emplace(key, idx); nodes_.push_back({key, expiration, std::move(callback)}); ShiftUp(idx); } else { Adjust(key, expiration, std::move(callback)); }` |
| `HeapTimer::Empty` | `assert(nodes_.empty() == key_to_idx_.empty()); return nodes_.empty();` |
| `HeapTimer::Size` | `assert(nodes_.size() == key_to_idx_.size()); return nodes_.size();` |
| `HeapTimer::ShiftUp` | `auto parent {Parent(idx)}; while (parent.has_value()) { assert(*parent < idx); if (nodes_[*parent] >= nodes_[idx]) { Swap(*parent, idx); idx = *parent; parent = Parent(idx); } else { break; } }` |
| `HeapTimer::ShiftDown` | `auto child {SmallChild(idx)}; while (child.has_value()) { assert(*child > idx); if (nodes_[idx] > nodes_[*child]) { Swap(*child, idx); idx = *child; child = SmallChild(idx); } else { break; } }` |
| `HeapTimer::Parent` | `return idx != 0 ? std::optional {(idx - 1) / 2} : std::nullopt;` |
| `HeapTimer::SmallChild` | `const auto left {idx * 2 + 1}; const auto right {left + 1}; if (ValidIndex(left) && left > idx) { auto smaller {left}; if (ValidIndex(right) && right > idx && nodes_[right] < nodes_[left]) { smaller = right; } return smaller; } else { return std::nullopt; }` |
| `HeapTimer::Swap` | `assert(ValidIndex(idx1) && ValidIndex(idx2)); if (idx1 != idx2) { nodes_[idx1].Swap(nodes_[idx2]); key_to_idx_[nodes_[idx1].key] = idx1; key_to_idx_[nodes_[idx2].key] = idx2; }` |
| `HeapTimer::Tick` | `while (!Empty()) { if (auto& node {nodes_.front()}; node.Expired()) { const auto callback {std::move(node.callback)}; const auto key {node.key}; Pop(); try { assert(callback); callback(key); } catch (const std::exception& err) { logger_->Log(log::Event::Create(log::Level::Error) << fmt::format("Exception raised in timer's callback: {}", err.what())); } } else { break; } }` |
| `HeapTimer::ToNextTick` | `Tick(); if (!Empty()) { const auto interval {nodes_.front().expiration - Clock::now()}; if (interval > Clock::duration::zero()) { return interval; } } return Clock::duration::zero();` |
| `HeapTimer::Pop` | `assert(!Empty()); return RemoveByIndex(0);` |
| `HeapTimer::Invoke` | `const auto idx {key_to_idx_.at(key)}; try { assert(nodes_[idx].callback); nodes_[idx].callback(key); } catch (const std::exception& err) { logger_->Log(log::Event::Create(log::Level::Error) << fmt::format("Exception raised in timer's callback: {}", err.what())); } RemoveByIndex(idx); assert(!Contain(key));` |
| `HeapTimer::RemoveByIndex` | `assert(ValidIndex(idx)); const auto key {nodes_[idx].key}; if (Size() == 1) { Clear(); return key; } nodes_[idx].expiration = Clock::time_point {Clock::duration::zero()}; ShiftUp(idx); assert(nodes_.front().key == key); nodes_.front().Swap(nodes_.back()); std::swap(key_to_idx_[nodes_.front().key], key_to_idx_[nodes_.back().key]); nodes_.pop_back(); key_to_idx_.erase(key); ShiftDown(0); assert(key_to_idx_.size() == nodes_.size()); return key;` |
