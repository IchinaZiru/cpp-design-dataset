# RegisterFile クラスの詳細設計仕様書

## 1. 目的
`RegisterFile` クラスは、RISC-V アーキテクチャのレジスタファイルをモデル化します。このクラスは、32個のレジスタ（x0からx31）を管理し、時刻 (`tick`) に応じて前回値 (`prev`) と次回値 (`next`) を更新します。

## 2. 依存関係
- `Immediate` 型: `src/Common/Common.h` で定義されています。
- `debug_immediate` 関数: `src/Common/utils.h` で宣言されています。

## 3. クラス図

```mermaid
classDiagram
    class RegisterFile {
        -static const int REG_NUM = 32
        -Immediate prev[REG_NUM]
        -Immediate next[REG_NUM]

        +RegisterFile()
        +tick()
        +read(int id) Immediate
        +write(int id, Immediate val)
        +debug()
    }
```

## 4. クラス・メソッド・インターフェース詳細

| メンバ/メソッド | 型/戻り値型 | 可視性 | 説明 |
|-----------------|-------------|--------|------|
| `REG_NUM`       | `static const int` | private | レジスタ数（32） |
| `prev`          | `Immediate[REG_NUM]` | private | 前回値を保持する配列 |
| `next`          | `Immediate[REG_NUM]` | private | 次回値を保持する配列 |
| `RegisterFile()` | - | public | コンストラクタ。`prev` と `next` をゼロ初期化します。 |
| `tick()`        | `void` | public | `prev` を `next` のコピーで更新します。 |
| `read(int id)`  | `Immediate` | public | レジスタ `id` の値を返します。`id == 0` の場合は `0` を返します。 |
| `write(int id, Immediate val)` | `void` | public | レジスタ `id` に `val` を書き込みます（`next[id]` に格納）。 |
| `debug()`       | `void` | public | レジスタの内容をデバッグ出力します。 |

## 5. メソッド仕様書

### `RegisterFile()`
- **目的**: `prev` と `next` 配列をゼロ初期化します。
- **副作用**: `prev` と `next` のすべての要素が `0` に設定されます。

### `tick()`
- **目的**: `prev` を `next` のコピーで更新します。
- **副作用**: `prev` 配列が `next` 配列の内容で置き換えられます。

### `read(int id)`
- **目的**: レジスタ `id` の値を返します。
- **引数**:
  - `id`: レジスタ番号（0から31）。
- **戻り値**: `id == 0` の場合は `0`、それ以外の場合は `prev[id]` の値。
- **前提条件**: `id` は `0 <= id < REG_NUM` を満たす必要があります（コードではチェックされていません）。

### `write(int id, Immediate val)`
- **目的**: レジスタ `id` に `val` を書き込みます。
- **引数**:
  - `id`: レジスタ番号（0から31）。
  - `val`: 書き込む値。
- **副作用**: `next[id]` が `val` に設定されます。
- **前提条件**: `id` は `0 <= id < REG_NUM` を満たす必要があります（コードではチェックされていません）。

### `debug()`
- **目的**: レジスタの内容をデバッグ出力します。
- **副作用**:
  - コンソールにレジスタ名と値が表示されます。
  - `debug_immediate` 関数が呼び出されます（`next[j]` の値を引数として）。
- **注意**: レジスタ名はハードコーディングされており、`rf_name` 配列で定義されています。

## 6. 処理フロー図

### `debug()` メソッドの処理フロー
1. `rf_name` 配列を初期化（静的）。
2. 4行×8列のグリッドでレジスタ名を表示：
   - 各行は8個のレジスタをカバーします。
3. 各行ごとに、対応する `next[j]` の値を `debug_immediate` で出力します。

```mermaid
flowchart TD
    A[Start] --> B[Initialize rf_name]
    B --> C[Loop i=0 to 3]
    C --> D[Loop j=i*8 to i*8+7]
    D --> E[Print register name (e.g., "#0", "ra")]
    E --> F[End inner loop]
    F --> G[Loop j=i*8 to i*8+7]
    G --> H[Call debug_immediate(next[j], 11)]
    H --> I[End inner loop]
    I --> J[Print newline]
    J --> K[End outer loop]
    K --> L[End]
```

## 7. 状態遷移・副作用

| 状態 | 更新条件 | 副作用 |
|------|-----------|--------|
| `prev` | `tick()` が呼び出されたとき | `prev = next`（メモリコピー） |
| `next[id]` | `write(id, val)` が呼び出されたとき | `next[id] = val` |

- **不変条件**:
  - `read(0)` は常に `0` を返します。
  - `prev` と `next` のサイズは `REG_NUM` (32) で固定です。

## 8. データ変換・制約

| 項目 | 説明 |
|------|------|
| レジスタ数 | `REG_NUM = 32`（x0からx31） |
| `Immediate` 型 | `unsigned int`（`Common.h` で定義） |
| `read(0)` の特殊処理 | x0 (zeroレジスタ) は常に `0` を返します。 |
| `debug()` の出力形式 | レジスタ名と値を20文字幅で整形して表示します。 |

## 9. 再実装注意事項
- `prev` と `next` 配列は `Immediate` 型（`unsigned int`）である必要があります。
- `tick()` は `memcpy` を使用して `prev` を `next` のコピーで更新します。
- `debug()` メソッドでは、ハードコーディングされたレジスタ名 (`rf_name`) が使用されています。この配列は静的です。
- `debug_immediate` 関数は外部依存であり、`utils.h` で宣言されています。

## 10. 完全再構築台帳

### ファイル構造
```cpp
#include "Common/Common.h" // Immediate 型の定義
#include <cstring>         // memset, memcpy
#include <iostream>        // std::cout, std::setw
#include <vector>          // std::vector
#include <string>          // std::string

class RegisterFile {
    static const int REG_NUM = 32;
public:
    Immediate prev[REG_NUM];
    Immediate next[REG_NUM];

    RegisterFile() {
        memset(prev, 0, sizeof(prev));
        memset(next, 0, sizeof(next));
    }

    void tick() { memcpy(prev, next, sizeof(prev)); }

    Immediate read(int id) { return id == 0 ? 0 : prev[id]; }

    void write(int id, Immediate val) { next[id] = val; }

    void debug() {
        static std::vector<std::string> rf_name = {"0", "ra", "sp", "gp", "tp", "t0", "t1", "t2",
                                                   "s0", "s1", "a0", "a1", "a2", "a3", "a4", "a5",
                                                   "a6", "a7", "s2", "s3", "s4", "s5", "s6", "s7",
                                                   "s8", "s9", "s10", "s11", "t3", "t4", "t5", "t6"};
        for (int i = 0; i < 4; i++) {
            for (int j = i * 8; j < i * 8 + 8; j++) {
                char buffer[20];
                sprintf(buffer, "#%d", j);
                std::cout << std::setw(20) << buffer
                          << std::setw(4) << rf_name[j];
            }
            std::cout << std::endl;
            for (int j = i * 8; j < i * 8 + 8; j++) {
                debug_immediate(next[j], 11);
            }
            std::cout << std::endl;
        }
    }
};
```

### 再実装に必要な具体的事実
1. `REG_NUM` は `32` で固定です。
2. `prev` と `next` 配列は `Immediate` 型（`unsigned int`）である必要があります。
3. コンストラクタでは `memset` を使用して両方の配列をゼロ初期化します。
4. `tick()` は `memcpy` を使用して `prev` を `next` のコピーで更新します。
5. `read(0)` は常に `0` を返します（x0レジスタはハードワイヤードされています）。
6. `debug()` メソッドでは、静的な `rf_name` 配列が使用されます。この配列は32個のレジスタ名を格納しています。
7. `debug_immediate` 関数は外部依存であり、`utils.h` で宣言されています。
