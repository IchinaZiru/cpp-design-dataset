IPv4Addr::IPv4Addr(sockaddr_in addr) : raw_ {std::move(addr)} {
    std::array<char, max_length + 1> ip;
    if (inet_ntop(version, &raw_.sin_addr, ip.data(), ip.size())) {
        ip_ = ip.data();
    } else {
        ThrowLastSystemError();
    }
}

IPv4Addr::IPv4Addr(std::string ip, const std::uint16_t port) :
    ip_ {std::move(ip)} {
    raw_.sin_family = version;
    raw_.sin_port = htons(port);
    if (inet_pton(version, ip_.data(), &raw_.sin_addr) != 1) {
        ThrowLastSystemError();
    }
}

## メソッド仕様書

### IPv4Addr::IPv4Addr(sockaddr_in addr)
- **目的**: sockaddr_in構造体からIPv4アドレスオブジェクトを生成する
- **引数**:
  - `addr`: 生のsockaddr_in構造体
- **動作**:
  1. raw_にaddrを移動代入
  2. inet_ntopでアドレスを文字列に変換
  3. 成功時はip_に結果を格納、失敗時は例外をスロー
- **副作用**: ip_とraw_の初期化
- **エラー処理**: inet_ntop失敗時にThrowLastSystemError()を呼び出し

### IPv4Addr::IPv4Addr(string ip, uint16_t port)
- **目的**: IP文字列とポートからIPv4アドレスオブジェクトを生成する
- **引数**:
  - `ip`: IPアドレス文字列 (例: "192.168.1.1")
  - `port`: ポート番号 (ホストバイトオーダー)
- **動作**:
  1. ip_にipを移動代入
  2. raw_.sin_family = AF_INET
  3. raw_.sin_port = htons(port) (ネットワークバイトオーダーへ変換)
  4. inet_ptonで文字列をアドレス構造体にパース
- **副作用**: ip_とraw_の初期化
- **エラー処理**: inet_pton失敗時にThrowLastSystemError()を呼び出し

### Port()メソッド (IPv4Addr/IPv6Addr)
- **目的**: ポート番号をホストバイトオーダーで取得する
- **戻り値**: ホストバイトオーダーのポート番号
- **動作**:
  - IPv4: ntohs(raw_.sin_port)を返す
  - IPv6: ntohs(raw_.sin6_port)を返す
- **副作用**: なし

### Raw()メソッド (IPv4Addr/IPv6Addr)
- **目的**: 生のsockaddr構造体へのポインタを取得する
- **戻り値**: reinterpret_cast<sockaddr*>(&raw_)でキャストしたポインタ
- **動作**:
  - raw_のアドレスをsockaddr*型にキャストして返す
- **副作用**: なし

### メモリ管理

- クラスメンバーはすべて値セマンティクスで管理
- raw_構造体は直接メンバーとして保持
- ip_文字列はstd::stringとして所有権を保持
- デストラクタはデフォルト実装（noexcept指定あり）

- コンストラクタのみ状態を変更
- スレッドセーフ: インスタンスごとに独立した状態を保持するため、同時アクセスがあればスレッドセーフ
