規則:
- 設計仕様書に記載された名前、型、signature、namespace、修飾子を変更しないでください。
- C++としてコンパイル可能なコードを生成してください。
- 設計仕様書に存在しない型、API、ファイル、unitを勝手に作らないでください。
- `replacement_required=true`と記載された置換unitだけを生成し、参照専用unitは生成しないでください。
- 各`content`には指定された置換unit本体だけを含めてください。function/byte-span unitでは周辺の`#include`、namespace wrapper、既存の定数・型・helper定義、別unitを複製しないでください。full-file/module-file unitでは`#include`、namespace、型、inline実装を含むファイル全体がunit本体であり、この除外規則の対象外です。
- function置換unitの`content`には、戻り値型、完全な関数名、引数list、修飾子、開閉波括弧、関数bodyを含む完全な関数定義を出力してください。関数body内の文だけを出力してはいけません。
- full-fileまたはmodule-file置換unitの`content`には、設計仕様書に記載された完全なファイルを先頭から末尾まで出力してください。include guardまたはpragma、必要なinclude、namespace、using、すべての型宣言、すべてのメンバー、すべてのinline実装、終端を省略してはいけません。代表的な関数一つ、宣言だけ、またはファイルの一部分だけを出力してはいけません。
- 設計仕様書で既存の周辺symbolとして示されたものは利用だけ行い、再定義しないでください。
- 設計仕様書に記載された変数型、初期値、条件式、比較演算子、分岐順序、更新順序、戻り値、error path、境界条件を逐語的に実装し、省略や等価な書き換えをしないでください。
- 設計仕様書で内容が確認不能とされた定数、table、型、APIを推測して作成しないでください。
- 出力前に、設計仕様書に列挙されたすべての正常経路・異常経路・終了条件が生成コードに存在することを内部確認してください。
- 指定されたJSON Schemaへ厳密に従ってください。
- JSON以外の説明やMarkdownを出力しないでください。
- C++記号をHTML entity化しないでください。
- 文字列、文字リテラル、template、concept、requiresを正しいC++構文で生成してください。

# HTTPサーバーライブラリ - 設計仕様書

## 概要
この設計仕様書は、HTTPリクエストとレスポンスを処理するためのC++ライブラリの実装を記述します。このライブラリは、HTTP/1.1プロトコルに準拠し、ファイルシステムから静的コンテンツを提供する機能を持っています。

## 名前空間
すべてのクラスと関数は`ws::http`名前空間内に配置されます。

## 依存関係
このライブラリは以下の外部ヘッダーに依存します：
- `containers/buffer.h`
- `ip.h`
- `util.h`

また、標準ライブラリから以下を使用します：
- `<filesystem>`
- `<iostream>`
- `<memory>`
- `<string>`
- `<string_view>`
- `<unordered_map>`

## 実装注意事項
1. **バッファ管理**：`IOBuffer`と`MappedReadOnlyFile`は、外部ライブラリによって提供されるものとします。
2. **エラーハンドリング**：例外を投げる関数では、適切なエラーメッセージを含む`std::invalid_argument`または`std::system_error`を投げます。
3. **スレッドセーフティ**：このライブラリはスレッドセーフではないため、呼び出し側で同期処理を行う必要があります。

## 使用例
```cpp
#include "http.h"

int main() {
    ws::http::ConnectionImpl::SetRootDirectory("/var/www");

    // ファイルディスクリプタを取得して接続を作成
    FileDescriptor fd = ...;
    auto connection = std::make_shared<ws::http::Connection>(fd, ip_addr);

    if (connection->Process()) {
        connection->Send();
    }

    return 0;
}
```
