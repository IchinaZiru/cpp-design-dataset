# Design Specification for RISC-V Instruction Decoding

## Overview
This specification documents the design of a RISC-V instruction decoding system implemented in C++. The code provides structures and methods to parse, validate, and debug RISC-V machine instructions.

## Core Components

### 1. Basic Types and Constants

#### `Instruction` Type
- **Type**: `unsigned int`
- **Purpose**: Represents a raw RISC-V instruction word (32 bits)

#### `Immediate` Type

- **Purpose**: Represents immediate values for various instruction formats

## Implementation Details

### Field Extraction
All instruction format structures extract fields using the same bit manipulation pattern:
1. Extract opcode from bits [6:0]
2. Extract register fields from their respective positions
3. Construct immediate value according to format-specific rules

### Immediate Value Construction
Each instruction type constructs its immediate value differently:
- **R-type**: No immediate (field unused)
- **I-type**: Sign-extended 12-bit immediate
- **S-type**: Complex construction from multiple bit fields
- **B-type**: Complex construction with special handling for bit[7]
- **U-type**: 32-bit immediate formed by shifting upper bits
- **J-type**: Complex construction with special handling for bit[20]

### Special Cases
1. **NOP Instruction**:
   - Created via `InstructionBase(0)`
   - Has special `inst == -1` marker
   - `is_nop()` method checks this condition

2. **Invalid Access Handling**:
   - Throws `InvalidAccess` exception when invalid field is accessed for instruction type
   - Validation performed via `verify()` method

## Usage Pattern
