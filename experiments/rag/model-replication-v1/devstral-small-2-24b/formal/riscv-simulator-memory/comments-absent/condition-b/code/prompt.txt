## 4. メソッド仕様書

### `check_addr(unsigned int addr)`
- **目的**: アドレスが有効かどうかをチェックする。
- **引数**:
  - `addr`: チェック対象のアドレス。
- **戻り値**: `bool` - アドレスが有効な場合はtrue、それ以外はfalse。
- **動作**:
  - `0 <= addr && addr < MEMORY_SIZE` の条件を満たす場合にtrueを返す。
- **副作用**: なし。

### `read_word(unsigned int addr)`
- **目的**: アドレスからImmediate型の値を読み取る。
- **引数**:
  - `addr`: 読み取り対象のアドレス。
- **戻り値**: `Immediate` - アドレスが有効な場合はmem[addr]から読み取った値、それ以外は0。
- **動作**:
  - `check_addr(addr)` がtrueを返す場合、`*(Immediate*)(mem + addr)` を返す。
  - それ以外の場合は0を返す。
- **副作用**: なし。

### `write_word(unsigned int addr, Immediate imm)`
- **目的**: アドレスにImmediate型の値を書き込む。
- **引数**:
  - `addr`: 書き込み対象のアドレス。
  - `imm`: 書き込む値。
- **戻り値**: なし。
- **動作**:
  - `check_addr(addr)` がtrueを返す場合、`*(Immediate*)(mem + addr) = imm` を実行する。
  - それ以外の場合は何もしない。
- **副作用**: メモリへの書き込み。

### `read_ushort(unsigned int addr)`
- **目的**: アドレスからunsigned short型の値を読み取る。
- **引数**:
  - `addr`: 読み取り対象のアドレス。
- **戻り値**: `unsigned short` - アドレスが有効な場合はmem[addr]から読み取った値、それ以外は0。
- **動作**:
  - `check_addr(addr)` がtrueを返す場合、`*(short*)(mem + addr)` を返す。
  - それ以外の場合は0を返す。
- **副作用**: なし。

### `write_ushort(unsigned int addr, unsigned short imm)`
- **目的**: アドレスにunsigned short型の値を書き込む。
- **引数**:
  - `addr`: 書き込み対象のアドレス。
  - `imm`: 書き込む値。
- **戻り値**: なし。
- **動作**:
  - `check_addr(addr)` がtrueを返す場合、`*(short*)(mem + addr) = imm` を実行する。
  - それ以外の場合は何もしない。
- **副作用**: メモリへの書き込み。

### `operator[](unsigned int addr)`
- **目的**: アドレスに対応するメモリ領域を参照または設定する。
- **引数**:
  - `addr`: アクセス対象のアドレス。
- **戻り値**: `unsigned char&` - アドレスが有効な場合はmem[addr]への参照、それ以外はplaceholderへの参照。
- **動作**:
  - `check_addr(addr)` がtrueを返す場合、`mem[addr]` への参照を返す。
  - それ以外の場合は`placeholder` への参照を返す。
- **副作用**: メモリへの書き込み（設定時）。

### `debug()`
- **目的**: 特定範囲のメモリ内容をデバッグ出力する。
- **引数**: なし。
- **戻り値**: なし。
- **動作**:
  - アドレス0x20000-0x10から0x20000までのメモリ内容を16進数でコンソールに出力する。
- **副作用**: コンソールへの出力。

## 追加詳細設計情報

### 完全再構築台帳
- **クラス名**: `Memory`
- **メンバ変数**:
  - `mem`: `unsigned char[MEMORY_SIZE]`（private）
