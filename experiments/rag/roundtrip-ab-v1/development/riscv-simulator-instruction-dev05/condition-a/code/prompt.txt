## メソッド仕様書

### `InstructionBase::bin_mask`
- **目的**: 指定されたビット数のマスクを生成する。
- **引数**: 
  - `digits`: ビット数 (int)
- **戻り値**: マスク値 (unsigned int)
- **動作**: `(1 << digits) - 1` を計算して返す。

### `InstructionBase::get_digits`
- **目的**: 指定された範囲のビットを抽出する。
- **引数**: 
  - `n`: 抽出元の値 (unsigned int)
  - `hi`: 高位ビット位置 (int)
  - `lo`: 低位ビット位置 (int)
- **戻り値**: 抽出したビット値 (unsigned int)
- **動作**: `(n >> lo) & bin_mask(hi - lo + 1)` を計算して返す。

### `InstructionBase::expand_digit`
- **目的**: 指定されたビットを拡張する。
- **引数**: 
  - `digit`: 抽出したビット値 (unsigned int)
  - `lo`: 低位ビット位置 (int)
- **戻り値**: 拡張したビット値 (unsigned int)
- **動作**: `digit ? (0xffffffff << lo) : 0` を計算して返す。

### `InstructionBase::is_valid`
- **目的**: 指定されたキーが有効かどうかを確認する。
- **引数**: 
  - `key`: チェック対象のキー (const std::string &)
- **戻り値**: 有効性 (bool)
- **動作**: タイプに応じて、指定されたキーが無効な場合 false を返す。それ以外は true を返す。

### `InstructionBase::verify`
- **目的**: 指定されたキーが有効かどうかを確認し、無効な場合は例外を投げる。
- **引数**: 
  - `key`: チェック対象のキー (const std::string &)
- **戻り値**: 無し
- **動作**: `is_valid(key)` を呼び出し、false の場合 `InvalidAccess` 例外を投げる。

### `InstructionBase::debug`
- **目的**: インストラクションのデバッグ情報を出力する。
- **引数**: 無し
- **戻り値**: 無し
- **動作**: インストラクションの opcode に応じて、適切な命令名を出力する。

### `InstructionBase::has_op1`
- **目的**: 命令がオペランド1を持っているかどうかを確認する。
- **引数**: 無し
- **戻り値**: オペランド1の有無 (bool)
- **動作**: タイプが U または J の場合は false を返す。それ以外は true を返す。

### `InstructionBase::has_op2`
- **目的**: 命令がオペランド2を持っているかどうかを確認する。
- **引数**: 無し
- **戻り値**: オペランド2の有無 (bool)
- **動作**: タイプが R, S, B の場合は true を返す。それ以外は false を返す。
