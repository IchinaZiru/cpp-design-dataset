## 4. メソッド仕様書

### check_addr(unsigned int addr)

- **目的**: アドレスが有効かどうかをチェックする。
- **引数**: `unsigned int addr` - チェックするアドレス。
- **戻り値**: `bool` - アドレスが有効な場合は `true`、それ以外は `false`。
- **動作**: 
  - アドレスが `0 <= addr < MEMORY_SIZE` の範囲内にあるかチェックする。
- **副作用**: 無し
- **エラー処理**: 無し

### read_word(unsigned int addr)

- **目的**: 指定されたアドレスからワードを読み込む。
- **引数**: `unsigned int addr` - 読み込むアドレス。
- **戻り値**: `Immediate` - 読み込んだワード。アドレスが無効な場合は `0` を返す。
- **動作**: 
  - アドレスが有効かチェックする。
  - アドレスが有効な場合、指定されたアドレスからワードを読み込む。
- **副作用**: 無し
- **エラー処理**: アドレスが無効な場合は `0` を返す。

### write_word(unsigned int addr, Immediate imm)

- **目的**: 指定されたアドレスにワードを書き込む。
- **引数**: 
  - `unsigned int addr` - 書き込むアドレス。
  - `Immediate imm` - 書き込むワード。
- **戻り値**: 無し
- **動作**: 
  - アドレスが有効かチェックする。
  - アドレスが有効な場合、指定されたアドレスにワードを書き込む。
- **副作用**: 指定されたアドレスのメモリ内容が更新される。

### read_ushort(unsigned int addr)

- **目的**: 指定されたアドレスからunsigned shortを読み込む。
- **引数**: `unsigned int addr` - 読み込むアドレス。
- **戻り値**: `unsigned short` - 読み込んだunsigned short。アドレスが無効な場合は `0` を返す。
- **動作**: 
  - アドレスが有効かチェックする。
  - アドレスが有効な場合、指定されたアドレスからunsigned shortを読み込む。
- **副作用**: 無し
- **エラー処理**: アドレスが無効な場合は `0` を返す。

### write_ushort(unsigned int addr, unsigned short imm)

- **目的**: 指定されたアドレスにunsigned shortを書き込む。

- **副作用**: 指定されたアドレスのメモリ内容が更新される。

### operator[](unsigned int addr)

- **目的**: 指定されたアドレスのメモリへの参照を返す。

- **戻り値**: `unsigned char &` - アドレスが有効な場合は指定されたアドレスのメモリへの参照、無効な場合は `placeholder` を返す。

## 完全再構築台帳

### src/Common/Memory.hpp

```cpp
#ifndef RISCV_SIMULATOR_MEMORY_HPP
#define RISCV_SIMULATOR_MEMORY_HPP

#include "Common.h"

class Memory {
public:
    unsigned char mem[MEMORY_SIZE];
    unsigned char placeholder;

    Memory() { memset(mem, 0, sizeof(mem)); }

    bool check_addr(unsigned int addr) {
        if (0 <= addr && addr < MEMORY_SIZE) return true;
        // TODO: there may be exception when checking address,
        //       I'm looking forward to solving this.
        // assert(false);
        return false;
    }

    Immediate read_word(unsigned int addr) {
        if (!check_addr(addr)) return 0;
        return *(Immediate *) (mem + addr);
    }

    void write_word(unsigned int addr, Immediate imm) {
        if (!check_addr(addr)) return;
        *(Immediate *) (mem + addr) = imm;
    }

    unsigned short read_ushort(unsigned int addr) {
        if (!check_addr(addr)) return 0;
        return *(short *) (mem + addr);
    }

    void write_ushort(unsigned int addr, unsigned short imm) {
        if (!check_addr(addr)) return;
        *(short *) (mem + addr) = imm;
    }

    unsigned char &operator[](unsigned int addr) {
        if (!check_addr(addr)) return placeholder;
        return mem[addr];
    }

    void debug() {
        for (int i = 0x20000 - 0x10; i <= 0x20000; i++) {
            std::cout << std::hex << (unsigned) mem[i] << " ";
        }
        std::cout << std::endl;
    }
};

#endif //RISCV_SIMULATOR_MEMORY_HPP
```
