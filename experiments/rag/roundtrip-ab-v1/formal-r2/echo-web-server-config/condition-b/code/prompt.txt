- 設計仕様書に記載された名前、型、signature、namespace、修飾子を変更しないでください。
- C++としてコンパイル可能なコードを生成してください。

- `replacement_required=true`と記載された置換unitだけを生成し、参照専用unitは生成しないでください。
- 各`content`には指定された置換unit本体だけを含めてください。function/byte-span unitでは周辺の`#include`、namespace wrapper、既存の定数・型・helper定義、別unitを複製しないでください。full-file/module-file unitでは`#include`、namespace、型、inline実装を含むファイル全体がunit本体であり、この除外規則の対象外です。
- function置換unitの`content`には、戻り値型、完全な関数名、引数list、修飾子、開閉波括弧、関数bodyを含む完全な関数定義を出力してください。関数body内の文だけを出力してはいけません。

- 出力前に、設計仕様書に列挙されたすべての正常経路・異常経路・終了条件が生成コードに存在することを内部確認してください。

### VarConverterクラス群

- **VarConverter<From, To>**: `static_cast`を使用して変換。
- **VarConverter<From, std::string>**: `std::to_string`を使用して変換。
- **VarConverter<std::string, std::string>**: 文字列をそのまま返す。
- **VarConverter<std::string, To>**: `std::istringstream`を使用して変換。失敗した場合は例外を投げる。
- **VarConverter<std::string, std::list<T>>**: YAMLノードからリストに変換。シーケンスでない場合は例外を投げる。
- **VarConverter<std::list<T>, std::string>**: リストからYAMLノードに変換し、文字列に変換する。
- **VarConverter<std::string, std::vector<T>>**: 文字列からリストに変換し、ベクタに移動する。
- **VarConverter<std::vector<T>, std::string>**: ベクタからリストに変換し、文字列に変換する。
- **VarConverter<std::string, std::set<T>>**: 文字列からリストに変換し、セットに移動する。
- **VarConverter<std::set<T>, std::string>**: セットからリストに変換し、文字列に変換する。
- **VarConverter<std::string, std::unordered_set<T>>**: 文字列からリストに変換し、非順序セットに移動する。
- **VarConverter<std::unordered_set<T>, std::string>**: 非順序セットからリストに変換し、文字列に変換する。
- **VarConverter<std::string, std::map<std::string, T>>**: YAMLノードからマップに変換。マップでない場合は例外を投げる。
- **VarConverter<std::map<std::string, T>, std::string>**: マップからYAMLノードに変換し、文字列に変換する。
- **VarConverter<std::string, std::unordered_map<std::string, T>>**: 文字列からマップに変換し、非順序マップに移動する。
- **VarConverter<std::unordered_map<std::string, T>, std::string>**: 非順序マップからマップに変換し、文字列に変換する。

### Varクラス

- **メンバ変数**:
  - `name_`: 変数名
  - `description_`: 変数の説明
  - `val_`: 変数の値
  - `listeners_`: 値変更リスナー
  - `mtx_`: 排他制御用ミューテックス

- **メソッド**:
  - `ToString()`: 変数の値を文字列に変換する。
  - `FromString(std::string_view str)`: 文字列から変数の値を設定する。
  - `GetValue()`: 変数の現在値を取得する。
  - `SetValue(const T& val)`: 変数の値を設定し、リスナーに通知する。
  - `TypeName()`: 変数の型名を返す。
  - `RemoveListener(std::uint64_t key)`: 指定されたキーのリスナーを削除する。
  - `AddListener(OnChange listener)`: リスナーを追加し、ユニークなキーを返す。
  - `ClearListeners()`: 全てのリスナーをクリアする。

### Configクラス

- **メンバ変数**:
  - `name_`: コンフィグ名
  - `vars_`: 変数マップ
  - `mtx_`: 排他制御用ミューテックス

- **メソッド**:
  - `Name()`: コンフィグ名を返す。
  - `Lookup(const std::string_view name, const T& default_val, const std::string_view description = "")`: 指定された名前の変数を探す。存在しない場合は新しく作成する。
  - `Lookup(const std::string_view name) const`: 指定された名前の変数を探す。型が一致しない場合は例外を投げる。
  - `LookupBase(std::string_view name) const noexcept`: 基本情報の変数を探す。
  - `LoadYaml(const YAML::Node& root)`: YAMLノードから既存の変数の値を設定する。
  - `Visit(std::function<void(VarBase::Ptr)> visitor) const noexcept`: 全ての変数に対してビジタ関数を呼び出す。
