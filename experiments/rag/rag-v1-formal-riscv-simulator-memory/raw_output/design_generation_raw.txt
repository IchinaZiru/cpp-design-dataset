# 設計文書: Memory クラス

## 概要
`Memory`クラスは、RISC-Vシミュレータのメモリ空間を管理します。このクラスは、メモリへの読み書き操作やアドレスチェック機能を提供します。

## 責務
- メモリ領域の初期化とクリア。
- アドレス範囲の検証。
- 単語（32ビット）、ハーフワード（16ビット）、バイト（8ビット）単位での読み書き操作。
- デバッグ用のメモリダンプ機能。

## 公開インターフェース

### コンストラクタ
```cpp
Memory()
```
- 説明: メモリ領域をゼロで初期化します。

### メソッド
```cpp
bool check_addr(unsigned int addr)
```
- 説明: 指定されたアドレスが有効な範囲内であるかチェックします。
- 入力: アドレス (`unsigned int`)
- 出力: 有効なアドレスの場合 `true`、それ以外の場合は `false`

```cpp
Immediate read_word(unsigned int addr)
```
- 説明: 指定されたアドレスから32ビット単位でデータを読み取ります。
- 入力: アドレス (`unsigned int`)
- 出力: 32ビットのデータ (`Immediate`)

```cpp
void write_word(unsigned int addr, Immediate imm)
```
- 説明: 指定されたアドレスに32ビット単位でデータを書き込みます。
- 入力: アドレス (`unsigned int`)、データ (`Immediate`)

```cpp
unsigned short read_ushort(unsigned int addr)
```
- 説明: 指定されたアドレスから16ビット単位でデータを読み取ります。
- 入力: アドレス (`unsigned int`)
- 出力: 16ビットのデータ (`unsigned short`)

```cpp
void write_ushort(unsigned int addr, unsigned short imm)
```
- 説明: 指定されたアドレスに16ビット単位でデータを書き込みます。
- 入力: アドレス (`unsigned int`)、データ (`unsigned short`)

### オペレータ
```cpp
unsigned char &operator[](unsigned int addr)
```
- 説明: 指定されたアドレスのバイト値への参照を返します。
- 入力: アドレス (`unsigned int`)
- 出力: バイト値への参照 (`unsigned char &`)

### その他のメソッド
```cpp
void debug()
```
- 説明: デバッグ用に特定の範囲のメモリ内容をダンプします。

## 入力
- アドレス (`unsigned int`)
- 書き込むデータ (`Immediate`, `unsigned short`)

## 出力
- 32ビットのデータ (`Immediate`)
- 16ビットのデータ (`unsigned short`)
- バイト値への参照 (`unsigned char &`)

## 状態
- メモリ領域 (`mem`: `unsigned char[MEMORY_SIZE]`)
- アドレスチェック用のプレースホルダー (`placeholder`: `unsigned char`)

## 処理手順
1. **コンストラクタ**: メモリ領域をゼロで初期化します。
2. **アドレスチェック**: 指定されたアドレスが有効な範囲内であるか確認します。
3. **読み込み操作**:
   - アドレスチェックを行い、無効な場合は0を返します。
   - 有効な場合は指定されたアドレスからデータを読み取ります。
4. **書き込み操作**:
   - アドレスチェックを行い、無効な場合は何もせずに終了します。
   - 有効な場合は指定されたアドレスにデータを書き込みます。
5. **オペレータ[]**: 指定されたアドレスのバイト値への参照を返します。無効な場合はプレースホルダーを返します。

## 例外・失敗条件
- アドレスチェックが失敗した場合、読み込み操作は0を返し、書き込み操作は何もせずに終了します。
- 無効なアドレスでオペレータ[]を使用した場合はプレースホルダーへの参照を返します。

## 依存関係
- `Immediate` 型の定義（具体的な型は不明だが、通常は32ビット整数）
- `MEMORY_SIZE` 定数の定義

## 重要な不変条件
- メモリ領域 (`mem`) のサイズは常に `MEMORY_SIZE` である。
- アドレスチェックは常に有効範囲内かを確認する。
