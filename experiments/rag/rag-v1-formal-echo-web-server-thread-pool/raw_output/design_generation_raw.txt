# デザイン文書: スレッドプールモジュール

## 概要
この設計文書は、Echo Web Serverプロジェクト内のスレッドプールモジュールについて記載しています。スレッドプールは並列処理を効率化し、リソースの使用を最適化するために使用されます。

## 責務
- 与えられたタスクを複数のスレッドで並列に実行します。
- タスクの追加とスレッドプールの開始・終了を管理します。
- スレッド間での同期とタスクキューの管理を行います。
- 例外処理を行い、エラーログを出力します。

## 公開インターフェース
### コンストラクタ
```cpp
explicit ThreadPool(std::optional<std::size_t> thread_count = std::nullopt,
                    log::Logger::Ptr logger = log::RootLogger()) noexcept;
```
- `thread_count`: スレッド数。指定しない場合や0の場合はハードウェアがサポートする並列スレッド数を使用します。
- `logger`: ロガーインスタンス。指定しない場合はグローバルなルートロガーを使用します。

### デストラクタ
```cpp
~ThreadPool() noexcept;
```

### 代入演算子とコピーコンストラクタ
```cpp
ThreadPool(const ThreadPool&) = delete;
ThreadPool(ThreadPool&&) = delete;
ThreadPool& operator=(const ThreadPool&) = delete;
ThreadPool& operator=(ThreadPool&&) = delete;
```
- コピーとムーブは禁止されています。

### メソッド
#### Start
```cpp
void Start() noexcept;
```
- スレッドプールを開始します。スレッドがタスクキューからタスクを取り出して実行するようになります。

#### Push
```cpp
void Push(Task task) noexcept;
```
- タスクをスレッドプールに追加します。
- `task`: 実行すべきタスク（`std::function<void()>`型）。

#### Close
```cpp
void Close() noexcept;
```
- スレッドプールを終了し、未処理のタスクは実行されません。

## 入力
- タスク（`std::function<void()>`型）
- スレッド数（オプション）
- ロガーインスタンス（オプション）

## 出力
- なし

## 状態
- `closed_`: スレッドプールが閉じているかどうかを示すフラグ。
- `tasks_`: タスクキュー（`std::list<Task>`型）。
- `threads_`: スレッドリスト（`std::list<std::thread>`型）。

## 処理手順
1. **コンストラクタ呼び出し**:
   - ロガーが指定されていない場合は、グローバルなルートロガーを使用します。
   - スレッド数が指定されていない場合や0の場合は、ハードウェアがサポートする並列スレッド数を使用します。

2. **Startメソッド呼び出し**:
   - `closed_`フラグをfalseに設定し、タスク実行用のスレッドを作成します。
   - 各スレッドは`ExecProc`メソッドで動作します。

3. **Pushメソッド呼び出し**:
   - タスクキューにタスクを追加し、待機中のスレッドに通知します。

4. **ExecProcメソッドの内部処理**:
   - タスクキューが空でないか、またはスレッドプールが閉じているまで待機します。
   - タスクキューからタスクを取り出し、実行します。
   - 例外が発生した場合はロガーにエラーメッセージを記録します。

5. **Closeメソッド呼び出し**:
   - `closed_`フラグをtrueに設定し、すべてのスレッドに通知します。
   - スレッドプール内の全てのスレッドが終了するまで待機します。

## 例外・失敗条件
- タスク実行中に例外が発生した場合、ロガーにエラーメッセージを記録します。ただし、例外は再スローされません。
- スレッドプールが閉じている状態でタスクを追加しようとすると、アサーションが失敗します。

## 依存関係
- `log::Logger`: ロギング機能を使用します。
- `std::thread`, `std::mutex`, `std::condition_variable`: スレッド管理と同期に使用します。
- `std::list`: タスクキューを実装するために使用します。

## 重要な不変条件
- スレッドプールが閉じている場合、タスクキューは空であるべきです。
- スレッドプールが開始されている場合、スレッドリストには少なくとも1つのスレッドが含まれるべきです。
