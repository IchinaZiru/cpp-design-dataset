# デザイン文書: Parser クラス

## 責務
`Parser`クラスは、入力ストリームからデータを読み取り、それをメモリに書き込む責任を持ちます。具体的には、16進数形式のデータを解析し、指定されたメモリオブジェクトに格納します。

## 公開インターフェース
- `static unsigned parse_hex(const std::string &hex)`
  - 機能: 16進数文字列を符号なし整数に変換する。
  - 引数: 
    - `const std::string &hex`: 変換したい16進数形式の文字列。
  - 戻り値: 変換された符号なし整数。

- `static void parse(std::istream &in, Memory &mem)`
  - 機能: 入力ストリームからデータを読み取り、メモリに書き込む。アドレス指定が含まれる場合がある。
  - 引数:
    - `std::istream &in`: データを読み取る入力ストリーム。
    - `Memory &mem`: データを格納するメモリオブジェクト。

- `static void parse_hex(std::istream &in, Memory &mem)`
  - 機能: 入力ストリームから16進数データを読み取り、4バイト単位でメモリに書き込む。
  - 引数:
    - `std::istream &in`: データを読み取る入力ストリーム。
    - `Memory &mem`: データを格納するメモリオブジェクト。

## 入力
- `parse_hex`メソッド: 16進数形式の文字列。
- `parse`メソッド: データが含まれる入力ストリームと、データを格納するためのメモリオブジェクト。入力ストリームはアドレス指定（@で始まる行）とデータ行を含む可能性がある。
- `parse_hex`メソッド: 16進数形式のデータが含まれる入力ストリームと、データを格納するためのメモリオブジェクト。

## 出力
- `parse_hex`: 符号なし整数（変換された16進数値）。
- `parse`および`parse_hex`: メモリオブジェクトへの書き込み結果。戻り値はなく、メモリオブジェクトが直接更新される。

## 状態
- 内部状態: なし（すべてのメソッドが静的であり、インスタンス間で共有する状態がない）。
- 外部依存: `Memory`クラスとそのインスタンスへの参照。

## 処理手順
1. **parse_hex メソッド**:
   - 引数として受け取った16進数文字列を、`strtol`関数を使用して符号なし整数に変換する。
   
2. **parse メソッド**:
   - 入力ストリームが有効であることを確認し、無効な場合はエラーメッセージを出力する。
   - 基本アドレス（`base_addr`）を初期化する。
   - ストリームから一行ずつ読み取り、その行の先頭文字が'@'の場合、基本アドレスを更新する。
   - 行の先頭文字が'@'でない場合、スペース区切りで16進数データを抽出し、それをメモリに書き込む。

3. **parse_hex メソッド**:
   - 入力ストリームが有効であることを確認し、無効な場合はエラーメッセージを出力する。
   - 基本アドレス（`base_addr`）を初期化する。
   - ストリームから16進数データを読み取り、それを4バイト単位でメモリに書き込む。

## 例外・失敗条件
- 入力ストリームが無効な場合、エラーメッセージを出力し処理を継続する。
- `parse_hex`メソッドにおいて、変換できない16進数文字列が与えられた場合の具体的な動作は未定義（`strtol`関数の仕様により0が返される可能性がある）。

## 依存関係
- `Memory`クラス: メモリへの書き込み操作に使用される。
- C標準ライブラリ: `strtol`関数を使用する。

## 重要な不変条件
- 入力ストリームは有効であるべき（無効な場合はエラーメッセージを出力する）。
- メモリオブジェクトへの参照が有効であるべき（メモリへの書き込み操作に使用される）。
