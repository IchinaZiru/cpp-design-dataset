# スレッドプールの設計仕様書

## 概要
このドキュメントは、`ThreadPool` クラスの実装と宣言を再現するための詳細な設計仕様を提供します。`ThreadPool` はタスクキューを使用して複数のスレッドで並列処理を行うクラスです。

## 名前空間
- `ws`

## インクルードファイル
- `log.h`
- `<condition_variable>`
- `<functional>`
- `<list>`
- `<mutex>`
- `<optional>`
- `<thread>`

## クラス定義: `ThreadPool`

### メンバ型
- `Task`: `std::function<void()>` 型のエイリアス。タスクを表す関数オブジェクト。

### コンストラクタ
- **シグネチャ**: `explicit ThreadPool(std::optional<std::size_t> thread_count = std::nullopt, log::Logger::Ptr logger = log::RootLogger()) noexcept;`
  - **パラメータ**:
    - `thread_count`: スレッドプール内のスレッド数を指定するオプション値。デフォルトは `std::nullopt`。
    - `logger`: ロガーのポインタ。デフォルトは `log::RootLogger()`。

### デストラクタ
- **シグネチャ**: `~ThreadPool() noexcept;`
  - スレッドプールを破棄する際にすべてのスレッドが終了するまで待機します。

### コピーとムーブセマンティクス
- コピーコンストラクタ、コピー代入演算子、ムーブコンストラクタ、ムーブ代入演算子は全て削除されています。

### パブリックメンバ関数

#### `Start`
- **シグネチャ**: `void Start() noexcept;`
  - スレッドプールを開始します。スレッドがタスクキューからタスクを取り出して実行するよう開始します。

#### `Push`
- **シグネチャ**: `void Push(Task task) noexcept;`
  - タスクキューに新しいタスクを追加します。
  - **パラメータ**:
    - `task`: 実行すべきタスクを表す関数オブジェクト。

#### `Close`
- **シグネチャ**: `void Close() noexcept;`
  - スレッドプールを終了し、すべてのスレッドが現在のタスクの実行を完了した後終了するようにします。

### プライバートメンバ関数

#### `ExecProc`
- **シグネチャ**: `void ExecProc() noexcept;`
  - スレッドプール内の各ワーカースレッドで実行されるプロセスです。タスクキューからタスクを取り出して実行し、例外が発生した場合はロガーを使用してエラーメッセージを出力します。

### プライバートメンバ変数

- `logger_`: ログ出力に使用するロガーのポインタ。
- `mtx_`: タスクキューへのアクセスを同期するために使用されるミューテックス。
- `closed_`: スレッドプールが終了しているかどうかを示すブール値。`true` の場合、スレッドプールはタスクを受け付けず、既存のタスクの実行を完了した後終了します。
- `thread_count_`: スレッドプール内のスレッド数。
- `cond_`: タスクキューが空でないことを待つための条件変数。
- `tasks_`: 実行待ちのタスクを保持するリスト。
- `threads_`: スレッドプール内のワーカースレッドを保持するリスト。

## 実装ファイル: `thread_pool.cpp`

### コンストラクタ実装
- ロガーが指定されていない場合はデフォルトロガーを使用します。
- スレッド数が指定されていない場合、ハードウェアのコア数を使用します。

### デストラクタ実装
- `Close` を呼び出してスレッドプールを終了し、すべてのワーカースレッドが終了するまで待機します。

### `Start` 実装
- スレッドプールが既に開始されている場合は何もせずに返ります。
- 指定された数のワーカースレッドを作成し、それぞれを `ExecProc` で実行させます。

### `Push` 実装
- スレッドプールが終了している場合は何もせずに返ります。
- タスクキューにタスクを追加し、条件変数を使用して待機中のワーカースレッドを通知します。

### `ExecProc` 実装
- タスクキューが空でないか、またはスレッドプールが終了しているかをチェックするラムダ関数 `not_empty_or_closed` を定義します。
- ワーカースレッドはタスクキューからタスクを取り出して実行し、例外が発生した場合はロガーを使用してエラーメッセージを出力します。

### `Close` 実装
- スレッドプールの終了フラグを設定し、すべてのワーカースレッドに通知します。これにより、ワーカースレッドはタスクキューからタスクを取り出すことを停止し、現在実行中のタスクが完了したら終了します。
